## Narration

1. 同样是繁华，材料里说，光谷步行街双休日每天人流七八十万，可不少老上海早已不去南京路，热闹为什么反而让人退避？
2. 反过来，被快速路切开的社区、千篇一律的街道，也会让人觉得憋闷，刺激太多不行，太少也不行，到底多少才刚刚好？
3. 先看环境知觉的特点：实验室可以一次只给一种刺激，真实环境却把声音、光线、人群和道路信息一起送过来，没有清楚的边界。
4. 我们注意到什么，还取决于自己正在做什么，同一个路口，司机可能盯着摄像头，行人更关心信号灯。
5. 环境提供的信息，往往远多于我们能处理的信息，所以人不是照单全收，而是不断筛选。
6. 刺激不足时，我们会主动找刺激；刺激超过处理能力时，就会进入感官超载，也就是 sensory overload。
7. 柏莱恩把四类特征称为对照刺激特性，英文是 collative stimulus properties，包括复杂性 complexity，也就是视觉丰富性；新奇性 novelty；让人惊喜或扫兴的意外性；以及不一致性。
8. 他的早期结论是，这些特征与美感评价之间呈倒 U 形，英文叫 inverted-U，也就是两头低、中间高。
9. 沃尔威尔进一步提醒：复杂性增加，兴趣和探索时间可能持续增加，但喜好却会先升后降，想多看，不等于喜欢。
10. 多伦多二十栋建筑的现场兴趣判断，以及建筑幻灯片的复杂度排序，都支持复杂性与兴趣之间的这种联系。
11. 两组住宅景观的比较、零售店标志复杂度的研究，也得到相近结果：越复杂，往往越能吸引探索。
12. 自然环境则是一个重要例外，相关研究中，复杂性增加时，偏爱也可能继续增加，不过不能理解成越密、越乱就一定越好。
13. 比如三水芦苞祖庙的陶脊，花纹、人物、小建筑层层叠叠，精彩程度可以和佛山祖庙相比。
14. 你可能愿意停下来辨认“三英战吕布”，却未必想把自己家的屋顶，也装成这样。
15. 同样，爱看赌城录像的人，真正喜欢的日常消费，可能只是网购打折商品，吸引眼球和适合生活，是两回事。
16. 所以，对人工环境来说，适中的复杂性通常更讨喜，过于简单和过于复杂，都可能让评价下降。
17. 但复杂不只看数量，还看组织：随机混种乔木可能只剩杂乱和单调；植物园分区、世界公园分主题，则让丰富的信息有章可循。
18. 再进一步，风景区或主题公园里，各个子环境各有特色，又彼此呼应，就是协同的复杂性，差异之中仍然有秩序。
19. 那为什么圣家寺看起来复杂、新奇、意外又不一致，却依然广受好评，难道倒 U 曲线失灵了吗？
20. 因为新奇里面也藏着熟悉：尖塔、玫瑰窗仍让人认出教堂，整体统一，又容得下细节的丰富。
21. 尚未完成带来的残缺美和期待感，加上天才般的另类表达，也说明喜好不能只用一个复杂度数字解释。
22. 再看二〇一七年北京凤凰国际传媒中心，莫比乌斯环式造型用了三千八百块尺寸和节点各不相同的幕墙玻璃，在约三十年前的二八六时代，很难以同样方式实现。
23. 从“偷菜”到“吃鸡”，从三维电影到三维巨幕、杜比全景声，再到玻璃栈道上的立体地景画，我们熟悉的刺激尺度变了，所谓中等复杂度也会跟着移动。
24. 这就接上沃尔威尔一九七四年提出的适应水平理论，英文叫 adaptation level：每个人都根据自身条件和过去经验，形成一条刺激基线。
25. 比如，经常接触拥挤的城市居民，对拥挤的适应水平，通常比农村居民更高，但这不是人人如此。
26. 当刺激远超基线，光谷广场平安夜的人山人海，或南京路的“人挤人、看人、喊人”，就可能变成信息超载。
27. 为了撑住，我们只盯公交和安全信息，沉默地当个“吃瓜群众”，甚至对不文明行为视而不见。
28. 这不一定是冷漠，也可能是注意资源不够用，长期超载还会让人头昏脑涨、烦躁易怒、注意力涣散。
29. 如果信息太多，同时又必须立刻行动，压力就有两层，比如西直门立交的标志牌，一次给出十项提示，司机还得及时选路。
30. 常被拿来对照的“七加减二”，其实是经典短时记忆容量的概括，不是道路注意力的硬上限，但十项提示仍可能增加处理负担。
31. 另一头是信息匮乏，英文叫 information underload：车流、高架和快速路把城市切成群岛，社区靠汽车、手机联系，老人和孩子却可能被隔绝。
32. 帕尔指出，混凝土森林会把封闭感强加于人，无聊和求刺激的心态，还可能促成破坏行为。
33. 自然的妙处就在于双向调节：对刺激过度的上班族，它能帮助恢复注意力，缓解紧张。
34. 对刺激不足的老人，它又能用变化、活动和交往丰富生活，增加活力，所以“天然镇静剂”并不等于让所有刺激消失。
35. 面对不匹配，可以先顺应，也就是选环境，教材所举的美国“同伴街”，按工作、生活习惯和情趣组织社区，当时销售额占新建住宅的百分之十五以上。
36. 也有人离开市中心，用更长的通勤换安静，“五环之歌”背后，就藏着这样的取舍。
37. 另一条路是适应，也就是改自己，但它有代价，教材中失明四十八年的按摩师詹宁斯，复明后反而慌乱，感叹“看不见真的比看得见要轻松”。
38. 亚马逊雨林姑娘雅莉玛，最终离开丈夫和孩子，回到雨林，也提醒我们，换个环境并不等于马上获得幸福。
39. 环境刺激与个人基线差得越远，反应往往越强，“少年处不得顺境，老年处不得逆境”可以启发思考，却不能当成人人适用的定律。
40. 所以，设计的学问，不是把刺激越堆越多，而是在倒 U 曲线上，寻找适合使用者的峰值。
41. 给游客多一点惊奇，给病人多一点秩序，也允许不同的人，选择不同的刺激水平。
42. 最后，给每个人留一片能调节刺激的自然，因为刚刚好，不是环境的固定分数，而是人与环境之间合适的关系。

## Parameters

参数性质：
以下曲线、评分和个人基线均为教学示意模型，不是研究拟合值或真实测量值。
复杂性与环境刺激量是不同变量，不作直接等同。
自然环境的单调关系只用于表达本课所述研究趋势，不外推到无限复杂度。
本脚本不引入空间坐标、角度或物理长度。

时长与句数：
T = 300 s，为目标成片朗读时长，实际 TTS 需校准语速和停顿。
允许时长区间：[280, 320] s。
N = 42 句。
第 1—2 句：开场，22 s。
第 3—6 句：环境知觉，35 s。
第 7—18 句：复杂性偏爱，85 s。
第 19—23 句：时代漂移，43 s。
第 24—39 句：适应水平，98 s。
第 40—42 句：收束，17 s。
分节时长为总时长预算，不是未经录音验证的实际句长。

核心曲线：
x = 归一化复杂性，范围 [0, 1]，单位：无量纲。
所有评价值范围为 [0, 1]，单位：无量纲；不同曲线共用尺度仅为教学比较。
I(x) = x，表示兴趣单调增加。
P(x) = 4x(1-x)，表示人工环境喜好的倒 U 曲线。
P 的峰值坐标：(x, P) = (0.5, 1)。
N(x) = x，表示自然环境偏爱的单调增加示意。
审计采样点 x：[0, 0.25, 0.5, 0.75, 1]。
对应 I 值：[0, 0.25, 0.5, 0.75, 1]。
对应 P 值：[0, 0.75, 1, 0.75, 0]。
对应 N 值：[0, 0.25, 0.5, 0.75, 1]。

峰值漂移模型：
a = 最受偏爱的复杂性位置，范围 (0, 1)，单位：无量纲。
当 0 ≤ x ≤ a 时，P_a(x) = 1 - ((x-a)/a)^2。
当 a ≤ x ≤ 1 时，P_a(x) = 1 - ((x-a)/(1-a))^2。
较早时期示意参数：a_old = 0.50。
较晚时期示意参数：a_new = 0.65。
示意峰值位移：Δa = 0.15。
上述年代比较不代表实测增幅，也不表示所有人的偏好都会右移。

四类对照刺激特性：
顺序固定为：复杂性、新奇性、意外性、不一致性。
评分范围：[0, 1]，单位：无量纲。
普通建筑的中等水平示意：[0.5, 0.5, 0.5, 0.5]。
圣家寺的高水平示意：[1, 1, 1, 1]。
评分仅表达课程中的理想化对照，不代表圣家寺各项特征已被客观测定为最高值。

复杂性组织：
类别编码为无量纲整数，仅作索引，不表示高低分。
0 = 无组织的复杂性。
1 = 有组织的复杂性。
2 = 协同的复杂性。

适应水平模型：
s = 环境刺激量，范围 [0, 100]，单位：示意刺激分。
b = 个人适应基线，范围 [0, 100]，单位：示意刺激分。
d = s-b，单位：示意刺激分。
d > 0 表示高于个人基线；d < 0 表示低于个人基线；d = 0 表示与基线匹配。
r = |s-b|/100，范围 [0, 1]，单位：无量纲，表示简化的反应强度。
该线性绝对差模型不表示真实心理反应必然线性，也不表示任何微小正差都已构成临床或行为意义上的超载。
较低基线示例：b_low = 40 示意刺激分。
较高基线示例：b_high = 60 示意刺激分。
高刺激示例：s_high = 80 示意刺激分。
低刺激示例：s_low = 20 示意刺激分。
自然调节示例：以 b = 60 为例，将 s = 80 或 s = 20 分别调节到 s = 60；该数值只示意双向趋近，不是自然环境的实测效应。

材料数字锚点：

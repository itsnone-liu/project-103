## Narration

1. 小海龟刚孵出来，就朝大海爬去，一些幼鱼也很早就会觅食、寻找藏身处，它们可没上过生存课。
2. 环境里的光、水流、气味和空间结构，已经提供了行动线索，人也会直接发现，这里能走，那里能躲。
3. 美国心理学家詹姆斯·吉布森把这种认识环境的方式，发展成生态知觉理论，ecological perception，也叫直接知觉理论。
4. 先看著名的视觉悬崖实验，埃莉诺·吉布森和沃克用棋盘格表面制造高低落差，再用结实的玻璃覆盖，让深处看起来像悬崖。
5. 经典实验的婴儿是六到十四个月大，愿意爬向浅侧的二十七名婴儿中，只有三名也爬向深侧，拒绝比例接近九成。
6. 玻璃明明可以承重，婴儿也能碰到它，可眼前的深度信息，仍然让多数婴儿不愿继续爬。
7. 不过，看出深度不等于害怕深度，不会爬的婴儿看到悬崖时也有心率变化，却不能单凭这一点就判定他们恐惧。
8. 爬行经验会改变婴儿对边缘的反应，所以把视觉悬崖概括成完全写进基因的恐惧，并不准确。
9. 十到十二个月左右，婴儿还会参考妈妈的表情，妈妈害怕，他们更容易退缩，妈妈微笑，他们更可能尝试通过。
10. 越接近觅食、藏身、逃生这些基本生存任务，人与其他动物越能表现出相似的知觉与行动联系。
11. 二战期间参与航空研究时，吉布森特别关注运动中的视觉，因为飞行员面对的，从来不是一张静止的照片。
12. 他所说的光阵列，optic array，是环境光在观察位置形成的结构化信息，不只是视网膜上的一幅图像。
13. 比如，地面上大小相同的纹理，越远看起来越密，这种质感梯度能提供表面延伸和距离关系的信息。
14. 身体一移动，光的信息也跟着变化，我们可以直接利用这些规律行动，不必先在脑中逐项推理。
15. 这里的直接，不是说神经系统完全不加工，而是强调，环境信息本身就能支持知觉，不必依赖复杂的内部推断。
16. 核心概念叫提供，affordance，也就是环境对某个行动者开放的功用可能性，比如可吃、可住、可走、可攀爬、可遮蔽。
17. 它不是物体自带的一张固定说明书，同一块石头，对成人可能可坐，对小婴儿却未必能爬上去。
18. 一根树枝可以当柴、手杖或工具，婴儿的抓握、吮吸则提示我们，早期行动倾向很重要，但发现用途也会受经验影响。
19. 社会环境同样提供行动线索，表情、语气、手势都能邀请或阻止互动，意大利人的丰富手势甚至被形容为第三张嘴。
20. 当物体迎面逼近，最紧急的问题是，还剩多久会碰上，这叫即将碰撞时间，time-to-collision，简称 TTC。
21. 吉布森在一九六二年前后的研究中关注到，对称扩大的图像会引发动物躲避，婴儿约四个月可出现防御反应，九个月时更明显。
22. 一九七六年，李提出陶理论，Tau theory，用视角除以视角变化速率，得到陶值，作为碰撞剩余时间的近似线索。
23. 在小视角、物体大小不变、正面匀速逼近这些条件下，这个近似很有用，但条件改变，就不能把它当成万能秒表。
24. 比如，目标相距十米，以每秒两米接近，碰撞还剩五秒，对一米宽的目标，陶值约为五点零零八秒。
25. 抢断、刹车、击球都需要把信息变成行动，优秀击球手靠能力与训练，而不是现场列力学方程，知觉和运动正是一枚硬币的两面。
26. 盖弗在一九九一年讨论了提供与知觉信息的关系，其中常用的三类是，虚假的、隐藏的和可察觉的提供。
27. 虚假的提供，是看起来能用，其实不能，比如没有实际作用的呼唤按钮，或者画在墙上、不能采光通风的假窗户。
28. 隐藏的提供，是能用却不容易发现，比如鞋子造型的酒瓶起子，或者被情侣发现可以当秋千的 U 形老藤。
29. 可察觉的提供，则是用途线索清楚，比如合适的椅子和楼梯，虚假线索容易诱发误用，隐藏线索则容易让人错过用途。
30. 儿童尤其喜欢探索这里能怎么玩，环境用得好，能支持成长，用得不好，就可能把探索变成事故。
31. 幼儿爱钻小空间，有人俗称猫耳洞习性，但这不证明人继承了猫科习性，幼儿园的小空间应便于查看，楼梯也不宜连续过长。
32. 所谓卡他行为，就是挤墙缝、卡栏杆、钻到器材下面，设计者要预判头、躯干或屁股会被哪里卡住。
33. 儿童也常爱攀爬、荡悠、滑行和钻洞，某些猴群研究出现过玩具偏好的性别差异，但不能简化成雄猴必爱车、雌猴必爱娃娃。
34. 有个树屋案例，贴警告、撤梯子都挡不住孩子，家长甚至托他们上去，可见标语不会自动取消环境中的攀爬机会。
35. 另一个案例里，低层公厕的缓坡屋顶加上旁边的矮垃圾箱，被组合成大滑梯，最后只能拆除，安全得看整条行动路线。
36. 陡坡接沙坑可用于攀爬，缓坡可滑板，平地可骑车、跳房子、踢球，浅水可戏水，但每一种都要结合能力与安全条件。
37. 沙坑还能挖、堆、塑形，有孩子可以玩两三个小时，丰富的行动可能性，往往比规定一种玩法更吸引人。
38. 南宁的鸟栖现象，是有人不坐凳面，却踩着凳子坐栏杆，潮湿清晨栏杆比较干燥，于是出现了设计者没预想的坐法。
39. 碗形盆栽却可能被当成垃圾盆，因为它的形状和高度正好适合随手投放，这就是忽视潜在用途带来的麻烦。
40. 所以设计不只要问，我安排了什么功能，还要问，这个人在这里能做什么，又可能怎样误用。
41. 生态知觉提醒我们，人类并不是站在自然之外的观察者，而是大自然孕育的物种之一。
42. 有些行动倾向来自演化，有些来自成长与练习，提供则始终存在于环境与行动者的关系中。
43. 尊重提供，发现提供，再把有益的机会留下、危险的机会改好，这是环境设计者的第一课。

TTC与Tau算例
逼近研究讲述年份：1962 年。
Tau理论提出年份：1976 年。
婴儿防御反应讲述年龄：约4月、约9月，不设为所有婴儿统一达到的阈值。
算例假设：目标为固定宽度的平面对象，始终正对观察者，沿中心轴直线匀速逼近，观察者不移动。
目标宽度 W = 1 m。
目标半宽 a = W/2 = 0.5 m。
初始中心距离 D_0 = 10 m。
接近速度 v = 2 m/s。
初始左右端点分别为 A_0 = (-0.5, 0, 10) m、B_0 = (0.5, 0, 10) m。
目标速度向量 u = (0, 0, -2) m/s。
D(t) = D_0 - vt，适用范围 0 s ≤ t < 5 s。
TTC(t) = D(t)/v。
TTC_0 = 5 s。
θ(t) = 2 arctan[a/D(t)]，θ为完整视角，单位：rad。
ω(t) = dθ/dt = 2av/[D(t)^2 + a^2]，单位：rad/s。
τ(t) = θ(t)/ω(t)，单位：s。
θ_0 = 2 arctan(1/20) rad ≈ 0.0999167914438855 rad。
ω_0 = 8/401 rad/s ≈ 0.0199501246882793 rad/s。
τ_0 = (401/4) arctan(1/20) s ≈ 5.00832917112476 s。
在本算例的几何与运动假设下，TTC(t) = sin[θ(t)]/ω(t)；τ≈TTC使用小视角近似sinθ≈θ。
初始绝对近似误差 E_abs = τ_0 - TTC_0 ≈ 0.00832917112476 s。
初始相对近似误差 E_rel = E_abs/TTC_0 ≈ 0.001665834224952，约为0.1665834224952%。
数值审计容差 ε = 10^-9；仅比较以所列单位表示的数值，不将不同量纲混算。

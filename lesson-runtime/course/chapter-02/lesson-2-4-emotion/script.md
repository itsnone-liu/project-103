## Narration

1. 同一天、同一平方公里里，你进新天地时期待，喷泉前尖叫，公园里微笑，到了旧城区却皱眉，什么变了？
2. 环境会迅速改变情绪，其中一根轴叫唤醒，arousal，一端欲眠，一端高度兴奋。
3. 脑干网状结构等系统参与调节皮层兴奋，强刺激还可能让心率、血压、呼吸和肾上腺素水平上升。
4. 可是，兴奋不一定快乐，害怕也能让心跳加快，所以读懂情绪，不能只有一根轴。
5. 人们常用美丽、愉悦、激动这些形容词描述环境，坎特在一九七四年指出，这些词彼此相关，可以归成少数类别。
6. 怎么分类呢，先把感受变成量表，比如很美丽、较美丽、一般、较不美丽、不美丽，让体验者选择。
7. 这种用两极形容词及中间等级来评分的方法，叫语义差别法，Semantic Differential，简称SD法。
8. 针对场所体验，我们先抓住两类词：美丽、愉悦偏向评价，激动、刺激偏向唤醒，每一类都能成为一根坐标轴。
9. 奥斯古特一九五七年的语义差别研究，就像给繁星般的词汇建立定位系统，把零散感受变成可比较的维度。
10. 拉塞尔和梅拉比安在一九七四年提出三因子：快乐到不快乐、控制到屈从、唤醒到欲眠。
11. 快乐很原始，多巴胺更关系到想要，脑啡肽等内源性阿片系统参与满足，但不是一种物质只负责一种感受。
12. 快乐是进化留下的奖赏，却不容易长驻，递质活动、应激调节和习惯化都会影响它的持续。
13. 范进中举般的狂喜会受到身体调节，人也常常不只追求快乐，还在努力躲开不快乐。
14. 控制感就是能不能自己做主，有时让人难受的，不只是辛苦，更是被迫屈从。
15. 课件引用的《商业周刊》调查称，超过百分之九十的企业家过劳，日均工作十一小时、睡六点五小时，百分之七十六仍说快乐。
16. 这说明累与快乐可以共存，控制感是可能的解释，但调查本身不能证明因果。
17. 自由受限时，人会想抢回自主，这叫心理对抗，reactance，也就是禁果分外甜。
18. 苏洵藏书，让苏轼兄弟偷读禁书的故事，常被用来说明这种心理，但属于轶事。
19. 反复努力仍改变不了处境，可能形成习得性无助，learned helplessness，并增加抑郁等风险。
20. 兰格和罗丁一九七六年的疗养院实验，一组强调员工照料，另一组强调自主选择，还让老人自己养护植物。
21. 三周后，自主组情绪更活跃，部分健康评价也更好，说明照料之外，还应留下选择。
22. 德国养老院全方位照顾却死亡率更高的说法，缺少明确出处，不能当作因果证据。
23. 再听一个未经核实的传说：布克在作坊里日误差小于百分之一秒，一五三六年入狱后，却造不出低于十分之一秒的钟表。
24. 注意，这两个误差门槛相差十倍，不是一千倍，也不是两只实物钟表的精确误差比。
25. 传说还据此推断金字塔由虔诚快乐的自由人建造，这个推论不能代替考古证据。
26. 拉塞尔和拉尼厄斯一九八四年，用瀑布、广告牌、荒野的幻灯片，让人评价四十个情绪词。
27. 课件记载三组样本量为二百三十四、一百八十和六十，实验还改变景物比例、大小和角度，包括翻转一百八十度。
28. 情绪词近似排成环，横轴是愉快度，pleasantness，纵轴是唤醒，中心较平淡，向外感受更强。
29. 沃德和拉塞尔一九八一年讨论了愉悦、唤醒、激动、放松四种描述，后两种可用前两轴旋转四十五度来理解。
30. 这里取顺时针旋转，激动和放松分别对应两条斜轴，并没有增加两个独立维度。
31. 高唤醒会让愉快或不快都可能更强，愉快加唤醒是激动、兴奋、美感，不快加唤醒则是厌恶、紧张、狂野。
32. 不快加欲眠是单调、乏味、麻木，愉快加欲眠则是安定、平静、放松，也就是心宽无处不桃源。
33. 回到新天地，入口整洁的咖啡座、维护良好的里弄和外文标志，可能带来中等愉悦、中等唤醒。
34. 中部雕塑喷泉和支弄口，让人拍照、搞怪、尖叫，愉快和唤醒一起升高。
35. 东行几十米到太平桥公园，空间豁然开朗，喷泉与层次丰富的绿化，让惊喜慢慢转成放松。
36. 再向东走约一百米，若进入杂乱、拥挤的旧城区，有些人会变得不快而紧张，但感受也因人而异。
37. 要注意，这四站按上述描述只覆盖三个象限，单调乏味才是缺少的第四类，评价环境就是辨认这些坐标。
38. 情绪坐标还能指导设计，耶克斯—多德森定律，Yerkes-Dodson Law，常用倒U形概括唤醒与任务表现的关系。
39. 唤醒太低容易没精神，太高可能慌乱，但最佳水平不是固定值，还取决于任务和个人。
40. 复杂的设计构思、数学演算，通常适合较低唤醒，简单描图、重复手工，则可能适合较高唤醒，轻松音乐有时能帮忙。
41. 娱乐观光场所可以用复杂性、意外性和神秘性吸引探索，但不是刺激越强越好。
42. 交通枢纽和医院更需要秩序与识别性，减少拥挤和焦虑，让人更容易找到路、完成任务。
43. 条件允许时，还应让个人微调室温、通风、光照和音乐响度，把一部分控制权交还给使用者。
44. 下次走进一个空间，试着问自己：愉快吗，清醒吗，能自己做主吗？
45. 愉快、唤醒、控制，三根轴不必替你决定感受，却能帮你说清感受，你就是自己的环境测评仪。

第三象限：P < 0，A < 0，代表乏味、麻木。

耶克斯—多德森关系的教学函数：
任务唤醒变量 a ∈ [0, 1]，无量纲；与前述有符号唤醒坐标的换算为a = (A + 1)/2。
复杂任务峰值位置 m_complex = 0.30。
简单任务峰值位置 m_simple = 0.70。
归一化绩效函数 q_complex(a) = 1 − (a − 0.30)²。
归一化绩效函数 q_simple(a) = 1 − (a − 0.70)²。
两函数在指定区间的值域均为[0.51, 1]，无量纲。
两函数峰值均为1，峰值位置相差0.40。
两函数在a = 0.50处相交，此时q = 0.96。
复杂任务两端值：q_complex(0) = 0.91，q_complex(1) = 0.51。
简单任务两端值：q_simple(0) = 0.51，q_simple(1) = 0.91。
这两条抛物线仅是定律的定性教学示意，不是定律唯一公式，也不是任何实验的拟合结果。

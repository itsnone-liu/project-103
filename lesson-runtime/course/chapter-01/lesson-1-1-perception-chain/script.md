## Narration

1. 清晨，你听到鸟鸣，瞥见鸟影，脱口而出“是麻雀”，就在这一瞬间，大脑已经跑完了一条三级流水线。
2. 感觉负责采集，知觉负责组织，认知负责理解，三者合作，才有了你眼中的世界。
3. 知觉研究是心理学最古老的研究领域之一，今天，我们用五分钟，拆开这条流水线。
4. 感觉，sense，就是感受器接收环境刺激，经神经通路，把信息送到大脑相应的区域。
5. 比如，光线到达视网膜，声波让鼓膜振动，物理刺激由此进入我们的信息加工系统。
6. 但刺激不是越小越能感觉到，刚刚能够察觉的最低强度，叫下绝对阈限，所以太微弱的声音，你可能听不见。
7. 刺激太强，又可能引起疼痛或损伤，因此，还可以用一个上限，描述人的可耐受范围。
8. 两个边界之间，可以粗略理解为“可感世界”，但不同感官的阈限并不相同，上限也不都简单等于痛觉出现。
9. 二十世纪五十年代，赫布与贝克斯顿等人限制受试者的感觉输入，用上半透明护目镜、隔声小室和帆布床。
10. 两三天后，有人就难以忍受，出现无聊、不安、思维受扰、测验成绩下降，甚至幻觉，可见没有明显伤害性刺激，不等于没有风险。
11. 婴儿更需要适宜刺激，但“意大利男孩托蒂蒙眼两周却终生失明”的故事证据不足，不能当成可靠实验。
12. 腓特烈二世“只喂食、不交谈、不触摸”的传闻，记载说的是婴儿夭折，而非终生哑巴，我们应记住发展需要刺激，而不是把传闻当证据。
13. 信息采集之后，轮到知觉，perception，也就是对感觉信息进行组织、识别和解释。
14. 你听见的并非只有一串声音，还会把它组织成鸟鸣，把零散轮廓识别成一只鸟。
15. 学习、记忆、期待和注意都在参与，所以知觉不是摄像机式的被动接收。
16. 格雷戈里的间接知觉理论强调这种“自上而下”的加工，而直接、生态取向的知觉理论，我们下一讲再展开。
17. 再往后是认知，cognition，也就是获得和运用知识的过程，其中一个核心是思维。
18. 皮亚杰把已有的知识经验结构叫图式，schema，婴儿早期的吮吸和抓握，就是图式的例子。
19. 孩子见过狗，第一次看到牛喊“大狗”，是在用旧图式吸收新经验，这叫同化，assimilation。
20. 反复发现牛和狗不同，孩子修改原有理解、建立新图式，这叫顺化，accommodation，也常译作顺应。
21. 可以粗略说，同化偏向旧结构里的量变，顺化涉及结构改变，而平衡、不平衡、新平衡，就是学习不断推进的过程。
22. 流水线还需要注意，也就是心理活动对对象的指向和集中：突然被鸟叫吸引，是无意注意。
23. 专心找鸟是有意注意，观察得入迷、不再费力维持，是有意后注意，刺激是否突出、你的目标和兴趣，都会影响注意。
24. 耶文斯的黑豆实验提示了加工限制：按常见教材概括，四粒以内几乎不出错，五粒起出现错误，八粒时错误率低于一半，九粒以上超过一半。
25. 所以，“七左右”只能当作这类任务的粗略界线，不是大脑的固定容量，而把九粒分成三组、每组三粒，通常会更容易判断。
26. 现在回到那只鸟，第一步，眼睛和耳朵接收刺激，形成感觉信息。
27. 第二步，把声音和外形与记忆中的表象联系起来，识别“这是一只鸟”，这是知觉。
28. 第三步，调用图式判断它熟不熟悉、有没有益处、是否有危险，这是认知。
29. 第四步，把信息存起来，或者采取行动：继续观察、赶鸟，甚至有人会打鸟或爬树寻找。
30. 这样重构出来的世界，叫“行为的环境”，它因人而异，并不等于客观环境；知觉和认知也有交集，比如认出黑色羽毛需要已有经验，而认知又连接着知觉与行动。
31. 这条流水线有三个容易误导我们的“漏洞”，第一个，是知觉定势，也就是经验预先设好了判断倾向。
32. 教材转述的黎柏三图实验中，先看少妇图十五秒，一组百分之百把两可图看成少妇，先看老妪图，另一组百分之九十六看成老妪，这不是普遍命中率。
33. 墨迹被佛罗里达人看成宇宙飞船、被贝都英人看成山丘的跨文化故事，也是在提醒我们：经验会影响解释。
34. 第二个，是习惯化和感觉适应，前者指反应逐渐减弱，后者指感受系统的敏感性变化，两者相关，但不完全相同。
35. “入芝兰之室，久而不闻其香”是熟悉的例子，高速公路旁的老住户可能睡得着，新住户却难以入睡，但习惯了不代表噪声没有影响。
36. 一八九七年，斯卓登戴上颠倒视野的装置，起初定向困难，约三天后有所减轻，到第八天协调明显改善，摘掉装置又需要重新适应。
37. 这说明，大脑会根据经验重新校准视觉与动作，而不是把世界原封不动地复制下来。
38. 第三个，是对变化的敏感度有限，韦伯定律说，在适用范围内，刚能察觉的刺激增量，与原强度的比值近似不变。
39. 假设这个比值是百分之一，一百支同样的烛光，要改变一支才刚能察觉，一千支就要改变十支。
40. 两次变化都是原强度的百分之一，所以能否察觉，不只看增加多少，还要看原来有多少，而且这个比例不是所有感觉共用的常数。
41. 费希纳进一步提出对数关系：在一定条件下，感觉量随刺激强度的对数增长，而不是刺激翻倍，感觉就一定翻倍。
42. 这给环境问题一个提醒：森林大火容易引发痛心，慢慢累积的污染却可能被忽视，但这也涉及注意和判断，不能只归因于韦伯定律。
43. 下次脱口而出“这是麻雀”，你就知道，这不是一个简单标签，而是采集、组织和理解共同完成的结果。
44. 这条流水线，经过漫长演化，也一直被你的经验重新塑造。
45. 而设计者的工作，就是给它恰当的信息，让环境更容易被感知、理解，并支持合适的行动。

## Parameters

时长与句数
- TTS 单位数：45 句。
- 目标总时长：300 s；允许范围：280–320 s。
- 分段时长预算，包含朗读与自然停顿：
  - 第 1–3 句：25 s；累计区间 [0, 25] s。
  - 第 4–12 句：60 s；累计区间 [25, 85] s。
  - 第 13–24 句：70 s；累计区间 [85, 155] s。
  - 第 25–30 句：45 s；累计区间 [155, 200] s。
  - 第 31–42 句：85 s；累计区间 [200, 285] s。
  - 第 43–45 句：15 s；累计区间 [285, 300] s。
- 以上为配音预算，不是特定 TTS 引擎的实测时长；最终音频需按 280–320 s 复测。

流水线
- 核心加工层级数：3 层，即感觉、知觉、认知。
- 鸟鸣案例的叙述步骤数：4 步，即接收、识别、判断、贮存或行动。
- “漏洞”类别数：3 类，即知觉定势、习惯化与适应、变化辨别限制。
- 注意类型数：3 类，即无意注意、有意注意、有意后注意。

阈限教学模型
- 刺激强度：I，单位随刺激类型确定，不跨感官共用。
- 下边界：I_low；上边界：I_high；约束为 0 ≤ I_low < I_high。
- 简化可感区间：[I_low, I_high]。
- 两个边界没有通用的实测数值，本脚本不虚构数值。
- 此区间是教学简化，不代表真实检测概率的硬切换；I_high 也不应统一解释为所有感官的痛觉阈限。

感觉剥夺与发展案例
- Hebb、Bexton 等人研究的年代范围：1950–1959 年。
- 旁白中“难以忍受”的概括时间：2–3 d，不表示全部受试者具有相同时间点。
- 托蒂故事中的蒙眼时间：2 周 = 14 d；这是待核实传闻参数，不是可靠实验数据。
- 腓特烈二世传闻的时代：13 世纪，即 1201–1300 年；传闻不能用于建立确定的因果结论。

理论与实验年份
- Gregory 理论参考年份：1987 年；不表示理论首次提出于该年。
- Jevons 黑豆实验年份：1871 年。
- Stratton 颠倒视野研究年份：1897 年。

黑豆任务
- 豆数 n：正整数，单位为粒。
- 错误率 p(n)：无量纲，取值范围 [0, 1]。
- 本课保留的教材概括如下，不能冒充完整原始数据：
  - 1 ≤ n ≤ 4：p(n) ≈ 0。
  - n = 5：开始出现错误，即 p(5) > 0，但未给出精确比例。
  - n = 8：0 ≤ p(8) < 0.5。
  - n ≥ 9：教材概括为 0.5 < p(n) ≤ 1，不作跨任务、跨人群推广。
- “七左右”：约 7 粒的教学性概括，不是由上述不等式唯一推导出的精确临界值。
- 分组例子：总量 9 粒；组数 3 组；每组 3 粒。
- 若代码阶段需要“分组后零错误”的示例，定义为理想化演示结果：错误次数 0 次；不能标记为 Jevons 实测错误率。

知觉定势案例
- 预先观看时间：15 s。
- 教材转述的少妇条件报告比例：100% = 1。
- 教材转述的老妪条件报告比例：96% = 0.96。
- 两组比例差：4 个百分点。
- 样本量未给出，不得由百分比反推人数，也不得视为普遍概率。

颠倒视野适应时间线
- 开始佩戴：t = 0 d，出现定向困难。
- 约 t = 3 d：困难有所减轻。
- t = 8 d：视觉与动作协调明显改善。
- 摘除装置：再次需要适应；本脚本不指定摘除的精确时刻或恢复耗时。
- 这些时间点是教学概括，不是人人适用的适应期限。

韦伯定律示例
- 基本关系：|ΔI| / I = k，I > 0。
- 本例设定：k = 0.01，无量纲；仅为教学假设。
- 烛光计数单位：支；假设每支光源相同、观察条件不变、有效刺激强度与支数成正比。
- 情况 A：I = 100 支等效烛光；|ΔI| = 1 支等效烛光。
- 情况 B：I = 1000 支等效烛光；|ΔI| = 10 支等效烛光。
- 增加后的计数：101 支、1010 支。
- 减少后的计数：99 支、990 支。
- 增减使用同一比例，是本例的对称近似，不是对真实视觉实验的无条件断言。

费希纳对数模型
- 量纲完整形式：E = a × ln(I / I_ref)，I > 0，I_ref > 0。
- ln 为自然对数，底数 e ≈ 2.718281828459045。
- 归一化教学设定：a = 1 个归一化感觉单位；I_ref = 1 支等效烛光。
- 因而，本例中的 E = ln(I / I_ref)，不是对带物理单位的 I 直接取对数。
- I_ref 是数学参考强度，不声称它是人类实际检测阈限。
- E(100) ≈ 4.605170186 个归一化感觉单位。
- E(1000) ≈ 6.907755279 个归一化感觉单位。
- E(1000) − E(100) ≈ 2.302585093 个归一化感觉单位。
- 小数计算审计容差：绝对误差 ≤ 10^-9。
- 本题没有指定坐标、角度或几何长度，不新增这些实现参数。

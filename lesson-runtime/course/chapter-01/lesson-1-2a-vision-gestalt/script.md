## Narration

1. 霍尔曾把中央凹的重要性说得很绝：没有它，就不会有机床、显微镜和望远镜，甚至可以说，没有科学。
2. 可我们平常看世界，只觉得眼前是一整片，根本没注意到里面还有分工。
3. 今天就把眼睛当成三支侦察队，看看它们怎样收集信息，再由大脑拼成整体。
4. 第一支是中央凹，英文 fovea，它是视网膜中央的小凹，里面的视锥细胞纤细而密集，负责分辨精细细节。
5. 它最精细的视野非常窄，可以近似看成一个圆锥，水平和垂直方向的总视角都只有两度。
6. 头直立时，视平线以下约十度常被用作自然注视方向的设计参考，展品高度、榻榻米住宅的细部位置，都可以考虑它，但不能只凭它决定。
7. 讲视敏度时，可以用距离眼睛三十点五厘米、直径零点三到六毫米的小圆举例，理解穿针、拔刺和雕刻需要多精细的分辨，不过这不是标准视力测试。
8. 第二支是黄斑，英文 macula，它是包含中央凹的椭圆形区域，教学中常用十二到十五度描述它的水平视角。
9. 所以，这两支队伍不是彼此分开的：中央凹负责最精细的部分，周边黄斑参与阅读，它们随着眼睛移动，接连取得清晰信息。
10. 第三支是周围视觉，英文 peripheral vision，它看细节不如中央区域，却对运动很敏感，有时还会让运动显得更强烈。
11. 比如从开阔公路驶入林荫道，近处行道树不断向后掠过，周围视觉带来的速度感变强，驾驶员就可能不自觉地减速。
12. 隧道入口也要考虑明暗适应，有的教学资料把一到三秒的短暂看不清称为“盲视”，但它不是人人固定的失明时间。
13. 因此，入口照明需要过渡，隧道内照明要尽量均匀，也要减少视线高度附近容易造成眩光的灯具。
14. 商业街常用摊群、广告、旗幡和灯光，给周围视觉提供丰富刺激，让人觉得热闹、有活力。
15. 疗养环境则往往选择大片树林、草地，以及开敞明亮的空间，减少杂乱刺激，让人更容易静下来。
16. 接下来看看中央凹怎么工作：视觉扫描，英文 scanning，不是匀速擦过每个地方，而是扫视和注视交替发生。
17. 可以把这种轨迹叫作点划式：“划”是快速转移目光、寻找信息，“点”是停下来，仔细辨认某个局部。
18. 注视位置和停留时间往往与兴趣、任务有关，雅尔布斯一九六七年的研究就发现，观看人物油画时，目光常集中在眼睛、鼻端下部和嘴唇。
19. 如果眼前只有铅灰天空、万顷碧波，或者反复重复的建筑，缺少值得停留的地方，就容易觉得单调，甚至产生视觉疲劳。
20. 所以景观需要注视点：建筑群中的尖塔、碧波中的白帆、草原上的蒙古包、沙漠中的驼影，都能给目光一个落脚处。
21. 以西湖为例，曲折的岸线和湖中三岛提供了丰富的中景，让人反复扫描时，还能发现不同的层次和关系。
22. 把它与面积更大的东湖比较，是为了说明“大”不等于“耐看”，而不是说东湖真的眼空无物，也不能把观看舒适度简单归结为睫状肌是否放松。
23. 看建筑时，目光常沿着线条和外轮廓移动，在檐口、入口，以及形态突然变化的地方停下来。
24. 看街道时，目光常在中景左右往返；看广场时，则可能围绕中心来回摆动，观察对象不同，扫描方式也会不同。
25. 收来的信息还需要组织，这就轮到格式塔，英文 Gestalt，出场了，它常译作“完形”，强调有组织的整体，源于二十世纪初的德国心理学学派。
26. 第一条是图底之分，英文 figure-ground：一九一五年的鲁宾两可图，以黑色为背景时看到白色花瓶，以白色为背景时则看到两张黑色侧脸。
27. 一些复明研究曾把图底区分描述为很早出现的视觉反应，但这不足以直接证明它完全是先天直觉，因为视觉经验和学习也会参与。
28. 阴阳太极图也能帮助理解图底互换：同一片形状，既可以被注意为图形，也可以退到另一片形状的背景里。
29. 什么东西容易成为图形呢，先看面积：在大片相近的背景里，小而突出的对象容易被注意到，就像万绿丛中一点红。
30. 再看对称：左右或上下关系明确的形态，通常更容易被组织成一个稳定、完整的对象。
31. 第三个条件是封闭，群山环抱的天池、边界完整的月洞门，都容易让人认出一个有边界的整体。
32. 第四个是运动，背景相对静止时，车流、喷泉等动态对象更容易把注意力吸引过去。
33. 第五个是独特，卢浮宫玻璃金字塔、悉尼歌剧院这样的形态，常因区别于周围环境而成为醒目的图形。
34. 反过来，麻将楼、骰子楼式的重复立面，可能让人难以分出主次；本课可用单元超过七个提醒自己检查重复，但七不是统一的注意上限，重复也不必然使人晕眩。
35. 第二条是群化，也就是把一些分散的东西看成一组，常见线索有邻近、相似、连续和封闭。
36. 邻近，英文 proximity，说的是距离近的对象容易被归成一组，夜空中的星座、草原上的蒙古包群，都能帮助理解。
37. 相似，英文 similarity，说的是外形、颜色等特征相近的对象容易归组，比如贵州屯堡相似的石板屋顶，会让其中高耸的望楼更突出。
38. 连续，英文 continuity，说的是目光倾向于沿着顺畅的方向组织信息，所以排成直线的一串点，很容易被看成一条线。
39. 但只有檐口标高相同，还不足以让两座风格迥异的建筑形成整体，因为连续只是线索之一，还要看其他关系是否协调。
40. 封闭，英文 closure，说的是即使边界有所缺失，大脑也可能补出完整形状，比如位置相互呼应的四个直角，能让人认出一个矩形。
41. 同样，四角柱子的敞厅也可能被理解为完整空间，城市广场转角和边界的衔接，则会影响人们能否认出它的整体。
42. 第三条是简化：当十二个圆沿椭圆排列时，我们往往先认出一个完整的椭圆点群，而不是十二个互不相关的圆。
43. 旁边再放一个同类圆，它可能暂时不属于这一组，但不是无论多近都被排斥，因为位置变化会改变归组，大脑倾向于选择简洁、稳定的组织方式。
44. 回头看，中央凹看得精，黄斑帮助阅读，周围视觉留意运动，而大脑把这些信息组织成整体。
45. 设计，就是预先安排好这幅拼图，让人第一眼更容易看出重点，也在继续观看时读懂空间，而不是被杂乱的信息淹没。

## Parameters

时长参数：目标范围为 280–320 s；本稿目标时长 T = 300 s，实际时长需经 TTS 试听校准。
旁白单元数：N_sentence = 45，每个编号对应一个 TTS 单元。
分节预算：第 1–3 句为 20 s；第 4–15 句为 90 s；第 16–24 句为 65 s；第 25–43 句为 110 s；第 44–45 句为 15 s。

角度约定：所有“视角”均指完整张角，不是半角；角度计算时，degree × pi / 180 转为 radian。
中央凹教学近似：水平完整张角 theta_f_h = 2°；垂直完整张角 theta_f_v = 2°；圆锥半顶角 alpha_f = 1°。
黄斑教学近似：水平完整张角 theta_m_h ∈ [12°, 15°]；对应水平半角 alpha_m_h ∈ [6°, 7.5°]。
黄斑垂直张角：原题未给定，不赋数值；不得仅凭水平张角反推出椭圆的另一轴。
区域关系：中央凹包含于黄斑，不是与黄斑互不重叠的区域。
周围视觉范围：原题未给全视野边界，不赋总角度，也不以“全视野角度减黄斑角度”计算面积。
注视方向参考：相对视平线的俯角 beta = 10°；若仰角为正，则垂直方向坐标 elevation = -10°；这是教学设计参考，不是所有人的固定注视姿态。

小圆观察距离：L = 30.5 cm = 305 mm = 0.305 m。
小圆直径：d ∈ [0.3 mm, 6 mm] = [0.0003 m, 0.006 m]。
小圆半径：r = d / 2，因此 r ∈ [0.15 mm, 3 mm]。
小圆角直径几何条件：小圆平面垂直于观察轴，圆心位于观察轴上，L 为眼睛到圆心的距离。
小圆完整角直径：theta(d) = 2 × atan(d / (2 × L))，结果单位为 radian。
角直径最小值：theta_min = 2 × atan(0.3 / 610) rad，约为 0.05636°。
角直径最大值：theta_max = 2 × atan(6 / 610) rad，约为 1.12709°。
角直径精确值以上述 atan 表达式为准，小数只用于核对；能否看见还受对比度、照明、视力和任务影响，不能仅由角直径判定。

隧道适应示例时长：t_adapt ∈ [1 s, 3 s]；仅表示原题给出的短暂看不清示例，不是固定生理时长，也不是神经医学“盲视”的定义。
扫描方式分类数：N_scan = 2，分别为扫视与注视；原题未给注视时长、扫描坐标或运动速度，不另行赋值。
建筑、街道、广场扫描示例数：N_scan_example = 3。
西湖湖中岛屿示例数：N_island = 3。
雅尔布斯研究引用年份：Y_yarbus = 1967 年。
格式塔学派年代：20 世纪初；不据此推定某个精确创立年份。
鲁宾两可图引用年份：Y_rubin = 1915 年。

格式塔主规则数：N_rule = 3，分别为图底之分、群化、简化。
易成为图形的条件数：N_salience = 5，分别为小面积突出、对称、封闭、运动、独特。
群化子规则数：N_group = 4，分别为邻近、相似、连续、封闭。
鲁宾两可图的本课解读数：N_rubin = 2，分别为一个花瓶和两张侧脸。
侧脸数量：N_face = 2；花瓶数量：N_vase = 1；二者是替代解读，不是同一次识别的物体总数。
封闭示例的直角数量：N_corner = 4；每个直角角度 angle_corner = 90°。
矩形内角总和：angle_rectangle_sum = 360°；四个直角只有在位置和方向支持矩形时，才构成本课所述封闭示例。
敞厅四角柱子数量：N_column = 4。

椭圆长轴、短轴、圆直径及额外圆的位置：原题未给定，不赋数值；不能据此断言额外圆在任何位置都不归组。

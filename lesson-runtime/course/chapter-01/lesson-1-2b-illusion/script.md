## Narration

1. 1999年5月16日下午五点，深圳华强路与深南路口，据案例记载，数千行人突然向北狂奔，汽车也慌忙避让。
2. 引爆恐慌的，只是一句“楼要垮了”，而当天晴空大风，快速移动的云，让施工中的摩天大楼看起来正在向前倾动。
3. 楼没有真的倒下来，但缺少稳定参照的知觉，加上一句危险暗示，却让人群作出了真实的逃命反应。
4. 这种把不动看成动的现象，属于似动错觉，英文叫 illusory motion，它不是眼睛坏了，而是大脑判断运动时，受到特定条件的干扰。
5. 第一种叫自动现象，autokinetic，意思是一个孤立、静止的对象，会被我们看成正在移动。
6. 比如黑夜里的一炷香，周围什么都看不清，盯着那个亮点久了，就可能觉得香头在慢慢飘动。
7. 问题在于缺少参照，所以导航灯采用闪动信号，也有助于降低把静止灯光误认成移动目标的风险。
8. 第二种叫闪动现象，stroboscopic，不同位置的影像接连出现，大脑把它们接成运动，电影、卡通和一些电动广告都利用了这类原理。
9. 第三种叫诱动现象，induced motion，周围的大物体在动，却让里面静止的小物体看起来在动。
10. 浮云掠过月亮，就是熟悉的例子，在简化模型里，月亮本身不动，如果把云当成参照，月亮就像朝云的反方向移动。
11. 2010年上海世博会天津馆也利用了这种体验，车厢静止，窗外景观掠过，再配上同步的速度显示，人就觉得列车正在飞驰。
12. 可同样的机制也会制造恐慌，2008年5月21日，成都猛追湾有人看见白云快速掠过电视塔顶，大喊“电视塔要倒了”，数百人随即逃离。
13. 前一个例子是在营造体验，后一个例子则叠加了群体暗示，提醒我们：错觉造成的行为后果，可能远比错觉本身严重。
14. 不只是运动会看错，平面图形里的渐变、辐射、密集排列和矛盾空间，也可能让人感到扭曲、运动、闪烁，甚至像在发光。
15. 资料记载，八十年代吐鲁番某宾馆，就用单元图形的排列制造动态感，给炎热环境添一点活力，打破空间的沉闷。
16. 另一个案例是格里高利把“咖啡墙错觉”用于伦敦旅馆立面，让本来平行的线条，看起来像是发生了倾斜。
17. 可一旦面积变大，又叠加玻璃反光和现场光线，实际效果就远不如纸面上清楚。
18. 所以，二维图案里的错觉，搬进三维建筑并不一定照样成立，设计不能只凭一张小样，就推断整个空间的体验。
19. 街头立体画则利用透视关系，让地面或墙面的画面，从特定位置看起来具有真实的深度。
20. 从简单的假窗户，到地陷、急流、冰隙，再到完整的童话世界，它们能让人仿佛踏进另一个空间，但这种真实感往往依赖观看位置。
21. 还有一种更容易影响日常判断的现象：坡度错觉，Hajnal在2016年的相关研究提示，某些条件下，小坡度会被低估，缓坡甚至像是平路。
22. 辽宁某公路的案例里，路面看起来很平，车辆制动解除后却自行倒溜，说明“看着平”不等于重力作用下真的平。
23. 南宁郊区一个路口建成新地标后，也有居民投诉：“这个标志怎么竖歪了？”
24. 实测却发现，标志没歪，是地面带着缓坡，人把倾斜的地面当成水平参照，反而觉得竖直的标志有问题。
25. 判断坡度不能只靠眼睛，还要结合触觉、动觉和可靠参照，安全地站一站、走一走，必要时再用仪器测量。
26. 接下来是漂浮错觉，levitation illusion，Spivack在1967年评价波士顿一所精神病院时，讨论过这种环境问题。
27. 走廊表面光滑、反光强烈，强光射入后，远处人的脚和膝盖难以辨认，地面边界也模糊，于是人像悬在半空。
28. 这种知觉上的不确定，可能让部分精神分裂症患者感到惊吓，原本只是材料和照明的选择，却变成了心理负担。
29. 游览、娱乐或观演空间，有时可以借它制造刺激，但医院、机场和车站，更需要清晰、确定、方便判断的环境。
30. 另一种叫怪相错觉，strange-face illusion，Caputo在2010年的实验中，让人在昏暗条件下，持续注视镜中的自己。
31. 实验使用二十五瓦白炽灯，灯放在身后的地板上，镜子半米见方，距离被试四十厘米。
32. 不到一分钟，就有人开始看见“怪脸”，约三分之二的人报告，自己的脸出现了严重变形。
33. 超过四分之一的人看见陌生人，还有人看见双亲，包括已经去世的亲人，或者猫、猪、狮子一类的脸。
34. 注意，这些是可能重叠的体验报告，不能直接当成互不重叠的人群比例，拼成一张饼图。
35. 一种相关解释是特罗勒效应，Troxler fading，当视线长时间固定在某处，周围不变的视觉信息可能逐渐淡出。
36. 在昏暗环境里，脸的整体线索变弱，大脑又尝试把剩下的鼻子、眼睛重新拼合，于是熟悉的脸可能变得陌生，这不是镜子里真的多了一个人。
37. 因而，商业空间可以有意识地利用镜面效果，但居住和办公空间要慎用大面积镜面，不能只考虑“显得更大”。
38. 园林里的镜面墙，到了阴天或黄昏，如果轮廓和反射难以辨认，也可能从梦幻变成惊悚，颇有一点“兰若寺”的气氛。
39. 最后看一个温和的例子：黑体字错觉，boldface illusion，Fujimoto在2013年讨论过，文字下面加一条线，会让文字显得更醒目。
40. 这里说的下划线宽度，是线条的粗细，不是长度，参考范围大约是字高的八分之一到六分之一。
41. 有人把这种轮廓强化，与“双眼皮偏爱”联系起来，但这更适合作为一种可能的解释，而不是已经证实的共同机制。
42. 古典建筑的檐口、柱础和窗套，也可以从强化边缘的角度理解，线脚不只装饰，还能帮助形体变得鲜明。
43. 类似的知觉偏差还有太阳、月亮的大小错觉，水面折射造成的位置误判，以及“看山跑死马”的距离判断。
44. 记住这条主线：错觉是大脑规则在特定条件下的副作用，娱乐场所可以借它造梦，医院、机场和车站则要减少歧义、保障安全。
45. 而下一次，你觉得一条路“明明很平”，先别急着相信眼睛，在确保安全的前提下，让自己的脚也投一票。

诱动现象教学模型：
坐标约定：采用局部视觉角坐标，x、y的单位均为rad；正x方向定义为云的运动方向。
模型限定：短时、局部平面近似，背景参照权重固定为1；不声称所有真实诱动效应均满足这一比例。
云的角速度向量 v_cloud = (1/100, 0) rad/s。
月亮的场景角速度向量 v_moon = (0, 0) rad/s；这是教学模型中的静止假设，不是月球天体运动参数。
月亮相对于云背景的速度 v_apparent = v_moon − v_cloud。
因此 v_apparent = (−1/100, 0) rad/s。
速度大小 |v_cloud| = |v_apparent| = 1/100 rad/s。

坡度低估教学模型：
实际坡度角 θ ≥ 0°；θ = 0°表示水平。
模型尺度参数 β = 2°。
视觉判断角 θ_hat = θ² / (θ + β)。
绝对低估量 Δθ = θ − θ_hat = βθ / (θ + β)。
当 θ > 0°时，相对低估率 r = Δθ / θ = β / (θ + β)，单位：无量纲。
该函数只表达“小坡相对低估较多、陡坡相对低估减少”的教学趋势，不是Hajnal研究的拟合式，也不代表普遍适用的实测规律。
校验取值：
θ = 0°；θ_hat = 0°；Δθ = 0°；r未定义。
θ = 1°；θ_hat = 1/3°；Δθ = 2/3°；r = 2/3。
θ = 2°；θ_hat = 1°；Δθ = 1°；r = 1/2。
θ = 10°；θ_hat = 25/3°；Δθ = 5/3°；r = 1/6。
θ = 20°；θ_hat = 200/11°；Δθ = 20/11°；r = 1/11。

怪相错觉实验条件：
白炽灯额定电功率 P = 25 W；该数值不是照度，不能据此直接得到lux值。
镜面宽度 L = 0.5 m。
镜面高度 H_m = 0.5 m。
镜面面积 A = 0.25 m²。
被试至镜面的报告距离 d = 0.4 m。
灯的位置仅给出“被试身后地板上”；精确坐标及灯至被试距离未给出。
现象出现时间描述：t_onset < 60 s，属于材料中的近似时间表述，不代表每个被试都满足该界限。
严重变形脸报告比例：p_deform ≈ 2/3。
其中2/3是用于表达“约三分之二”的精确数学锚点，不是声称实验实测比例恰好等于2/3。
陌生人脸报告比例：p_stranger > 1/4，且 p_stranger ≤ 1；具体数值未给出。
双亲、动物及其他脸的报告比例未给出。
类别允许重叠；不存在可由现有材料计算出的“其余比例”。
这些比例不能作为互斥类别直接生成饼图，也不能以1 − p_deform − p_stranger推算其他体验的比例。

下划线比例：
字高 h > 0，单位可采用任意一致的长度单位。
下划线粗细 w的参考区间：h/8 ≤ w ≤ h/6。
比例区间：1/8 ≤ w/h ≤ 1/6，即0.125 ≤ w/h ≤ 0.166666…。
纯数值校验例：h = 24 mm，w_min = 3 mm，w_max = 4 mm。
该例只用于验证比例，不规定实际字体、字号或制作尺寸。
檐口、柱础、窗套属于边缘强化的类比，不把上述比例直接规定为建筑构件尺寸。

知觉策略分类：
分类标签数 K = 2，单位：类。
类别A：游览、娱乐、观演；在安全边界内可采用复杂、不定的刺激。
类别B：医院、机场、车站；优先提供简单、确定、便捷的判断线索。
此二分为教学策略，不是测量量表，也不意味着类别A可以忽略安全。

## Narration

1. 鸟儿落在电线上，常常隔着一段距离排开，谁也不挤着谁。
2. 杭州西湖边，游人坐下来洗脚，也会不约而同地给旁人留个空儿。
3. 如果一个陌生人无故靠到你五十厘米以内，你可能立刻觉得被冒犯；这不是矫情。
4. 霍尔在一九六三年把研究这类距离行为的领域称为“空间接近学”，英文是 Proxemics。
5. 你可以把个人空间想成身体周围一只看不见的气泡。
6. 它大致是腰以上呈圆柱形、腰以下逐渐收尖的形状，而不是地上一个固定的圆。
7. 气泡跟着人移动，也会随关系和场合胀缩；被无故闯入时，人容易焦虑。
8. 怎么量它？海杜克讨论的“止步距离法”，英文叫 stop-distance，从三米外让助手面无表情地慢慢靠近。
9. 你第一次说“有点不舒服”时的距离叫 D1，继续靠近到“相当不舒服”时的距离叫 D2。
10. D2 比 D1 更近；小于 D1 算进入个人空间，按这套指标，D1 除以 D2 越小，敏感性越高。
11. 一项阅览室实验里，陌生助试者紧挨女生坐下，三十分钟内约七成女生离座；对照组只有百分之十三。
12. 隔开一张桌子或一把空椅，离座几乎不发生；被靠近时，人还会转身、收肩、用书隔开，最后干脆离开。
13. 霍尔把人际距离分成四段，每段又有近、远之别；为方便比较，我们暂用各段的数值中点划分近远。
14. 第一段是密切距离，零到零点四五米；靠得这么近，气味和身体的热度都很明显。
15. 这里以触觉为主，可以是抚爱或安慰，也可能是争执甚至格斗，关系和情境决定感受。
16. 对陌生人来说，闯进这段距离往往非常难受；近远两档的分界，在我们的划分里是零点二二五米。
17. 第二段是个人距离，零点四五到一点二米，你可以先把它理解成一臂长左右。
18. 在这里，眼睛容易对焦，也看得清对方的细节，表情和语气都能提供丰富反馈。
19. 亲属或密友常在这段距离里谈心；按区间中点划分，零点八二五米是近、远两档的界线。
20. 第三段是社会距离，一点二到三点六米，通常可以用正常音量说话，适合处理不那么私人的事。
21. 距离稍远些时，约六十度的垂直视野更容易把对方全身收进来；这一段的中点是二点四米。
22. 和营业员谈业务，站在社会距离通常更自在；要是对方热情到贴近身边，反而可能惹人烦。
23. 第四段是公共距离，三点六到七点六米，中点是五点六米，常见于演讲或演出。
24. 到了这里，就得提高声音、放慢语速，动作和表情也要更明确；交流越来越依赖听觉和视觉。
25. 为什么我们会有这只气泡？一种进化推测认为，它兼有预警和防卫的作用。
26. 芬彻和桑希尔在二〇一二年提出，陌生同类可能带来未知病原体，留出距离或许能降低风险。
27. 黑死病和美洲遭遇外来病菌的历史说明疾病风险真实存在，但不能单凭史实证明气泡起源于防病。
28. 恶心也会影响回避：韦斯菲尔德等人在二〇〇三年的研究发现，妈妈更能容忍自己孩子的尿布。
29. 彭明等人在二〇一三年发现，当“陌生人”和“恶心源”同时出现时，人会更快回避。
30. 大脑研究也给出线索：霍尔特等人在二〇一四年用功能性磁共振成像，研究人脸靠得过近时的反应。
31. 此时，背侧顶内沟和腹侧前运动皮层的耦合增强；个人空间越大，这种耦合效应反而越弱。
32. 这说明距离感有可观察的神经关联，不过，“有关联”还不能说成某个脑区独自制造了气泡。
33. 气泡大小也因人而异：一些研究中，焦虑者、外控者和有暴力倾向者会留出更大空间。
34. 喜欢谁也有影响；比如女性面对自己喜欢的人，可能愿意站得更近。
35. 文化习惯同样不同：地中海地区常见近距交往，北欧和北美更习惯较大距离，交谈时就可能一进一退。
36. 设计空间时也可以考虑这种需求：小亭子利于人们相聚，是社会向心空间；候车室成排座椅则偏社会离心。
37. 再看长椅的“两头忙”：想多待一会儿的人，常偏爱端部、转角和边缘。
38. 所以，L 形座椅或曲尺形坐墙，往往比一条毫无变化的直线更能吸引人坐下。
39. 芦原义信用建筑间距 D 除以高度 H：比值小于一偏接近，大于一偏远离，二就是远离一侧的例子。
40. 比值大于四时，建筑之间的影响很弱；想看清景观全貌，观赏距离也常取对象高度的至少四倍。
41. 下次在地铁里觉得别扭，你就知道了：那只看不见的气泡，叫个人空间。
42. 而设计者的工作，就是给千万只气泡留出各自安放的空间。

## Parameters

- 时长目标：280–320 秒；分节预算依次为 30、60、90、60、50、10 秒，合计 300 秒。
- 旁白：42 句；对应段落为第 1–4、5–12、13–24、25–32、33–40、41–42 句。
- 距离均指人与人之间的距离，单位为米（m）；不指定空间坐标或人物身高。
- 开场靠近距离：50 厘米＝0.50 米。
- 四段边界：0、0.45、1.20、3.60、7.60 米。为使边界归属唯一，采用密切距离 `[0, 0.45)`、个人距离 `[0.45, 1.20)`、社会距离 `[1.20, 3.60)`、公共距离 `[3.60, 7.60]`，单位均为米。
- 近、远亚档**仅为本片按区间中点所作的数值划分**，不作为霍尔另行规定的精确分界：密切段中点 0.225 米，个人段 0.825 米，社会段 2.40 米，公共段 5.60 米；每段的近档不含中点，远档含中点。
- 止步距离法：助手起点 3.00 米；D1 为首次报告“有点不舒服”时的距离，D2 为报告“相当不舒服”时的距离，单位均为米。在两次报告均发生的有效测量中，`0 < D2 < D1 ≤ 3.00 米`；侵入范围为距离小于 D1，敏感性指标为无量纲比值 `D1/D2`。D1、D2 没有统一的预设实测值。
- 阅览室实验：观察时长 30 分钟；紧挨落座组离座比例约 70%，对照组 13%；两组比例差约 57 个百分点。
- 垂直视野角：约 60 度。未指定被观察者身高，因此不把“在社会距离内看见全身”设为对所有距离都成立的几何保证。
- 建筑间距与高度：D、H 的单位均为米，且 `H > 0`；`D/H` 无量纲。判读线为 1、2、4：小于 1 偏接近，大于 1 偏远离，2 是大于 1 的例值，大于 4 时相互影响很弱。景观观赏距离建议值为 `D ≥ 4H`。
- 文献年份：霍尔 1963 年；海杜克 1983 年；韦斯菲尔德等 2003 年；芬彻与桑希尔 2012 年；彭明等 2013 年；霍尔特等 2014 年。

## Math-check

- `30 + 60 + 90 + 60 + 50 + 10 = 300` 秒。
- `4 + 8 + 12 + 8 + 8 + 2 = 42` 句。
- `50 厘米 = 0.50 米`。
- `3.00 米 = 300 厘米`。
- `0 < 0.45 < 1.20 < 3.60 < 7.60`，单位为米。
- `(0 + 0.45) / 2 = 0.225` 米。
- `(0.45 + 1.20) / 2 = 0.825` 米。
- `(1.20 + 3.60) / 2 = 2.40` 米。
- `(3.60 + 7.60) / 2 = 5.60` 米。
- `1.20 ≤ 3.00 < 3.60`，即止步法起点数值落在社会距离段。
- 在 `0 < D2 < D1` 的条件下，`D1/D2 > 1`。
- `30 分钟 = 1800 秒`。
- `70% − 13% = 57` 个百分点。
- 在 `H > 0` 的条件下，`D = 2H ⇒ D/H = 2 > 1`。
- 在 `H > 0` 的条件下，`D ≥ 4H ⇔ D/H ≥ 4`。

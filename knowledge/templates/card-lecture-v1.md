# 模板：卡片式课件（card-lecture）v1

状态：生产可用（多支章节视频已产出：envpsy-t1-61-hr、envpsy-t2-94、envpsy-t3-intro、envpsy-t4-91 等，均通过 QA 并经用户认可为生产路线）
代表样本：`runs/envpsy-t2-94/`（成都茶馆，40 cues ≈5min，1920×1080）
本文件为 2026-10-14 补写正式版（此前仅以生产实践存在），版式描述直接摘自 t2-94 渲染代码。

## 1. 何时选此模板

- 知识点讲解型短章节片（taxonomy T1 概念图解主力、T5 章末 recap）：一节教材 → 40 上下 cue → 约 5 分钟。
- 信息密度优先、生产稳定性优先、批量生产（60+ 支排产）场景。
- 与动画纪录片式互斥选择：叙事/氛围优先的中长片选动画式；章节讲授选本模板。

## 2. 固定版式骨架（t2-94 实测）

- **纸张底 + 印刷网格**：纸色底、48px 细印刷格线（确定性，仅坐标函数）。
- **页眉带**（高 111px，navy 底 + 金色细条）：章节标题 | 节号/节名 | 系列标语。
- **左知识卡**（736×648）：kicker 药丸标签 + 大标题 + 分隔线 + 导语大字（字号按长度 5 档自适应）。
- **右场景画布**（900×600 圆角，独立 clip）：逐 cue 场景插画/信息图（茶馆样本含 popup/blend/streetcity/research/methods/district/formula/compare/distribution/siting/river/behavior/clusters/design/final 等场景函数族）；数据来源小字角标画在画布内。
- **底部旁白带**（高 236px，navy 底 + 金条）：旁白标签 + cue 计数"NN / 40" + 全句字幕常显（与上方教学图表区分离）。
- 入场动效：0.15 归一化时长的纸面淡入。

## 3. 生产管线与纪律

- 同一 103 管线（sol codegen + WEB_2D 确定性渲染 + QA + audio.py 时序倒置）。视觉上下文注入（topic brief + StepA + style_note）同样必开——否则退化为重复骨架页。
- 每节先写 decision_stepA（视觉语言/渲染技术/最大风险三段，t2-94 样式），数字口径与"示意≠史料"纪律在 StepA 就锁定。
- 验收门：QA 报告 + 联系表 + 数字口径审计；章节片历史上走过 `--visual-repair NOTES.md` 定点修复（见各 run 的 visual-repair-notes.md）。

## 4. 优点与边界（与动画式互参）

- 优点：结构稳定可批量；知识卡承载密度高；字幕常显利于检索复习；生产/修复路径成熟。
- 边界（即用户指出的通病）：构图骨架 40 次重复，叙事氛围弱——长片或案例叙事不可用本模板（那是动画纪录片式的领地）；两者按内容类型分派，不混用同一支片。

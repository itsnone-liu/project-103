# 模板：动画纪录片式（animation-documentary）v2

状态：v1 用户验收通过（2026-10-14"突破性"）；**v2 已产出**（`runs/envpsy-case1-v2/`，661.29s，48 cues，口语化旁白+中段专属世界语法，16 关键帧 VLM 语义实证，待用户验收）
代表作：v1=`runs/envpsy-case1-full/`（601.18s）；v2=`runs/envpsy-case1-v2/`（661.29s，BGM on）
上游规范：`VISUAL_DIRECTION.md`（各 run 自带，含六幕逐段视觉方案；v2 版含中段硬规则）

## 1. 何时选此模板

- 叙事型内容：真实场所/案例/政策/历史的过程性讲述（taxonomy 的 T2 案例解析、T3 学科史叙事尤其适配）。
- 需要"纪录片感"的多样构图：观众预期是"看片"而不是"看讲义"。
- 与卡片式互斥选择：卡片式适合概念图解短章节（T1 主力、信息密度优先）；本模板适合叙事与语义氛围优先的中长片。

## 2. 核心设计原则（母本 VISUAL_DIRECTION.md 提炼）

1. **按内容选技法，不统一版式**：每一段的视觉语法由该段叙事内容决定；卡片允许出现，但全片绝不重复同一骨架，无固定页眉/页脚/进度 HUD。
2. **每幕一种主导语法**（Times Square 六幕示范）：
   - 开场：同机位对位街景（改前/改后同地理，不虚构精确尺寸）
   - 决策幕：桌面文档舞台（便笺/备忘录/账本/报纸，道具化叙事，无虚构引语/日期/金额）
   - 利益相关方幕：分格 POV 世界（商户/司机/行人/通勤者各自画面语法→汇聚到一张共享街道平面）
   - 分析透镜幕：全幅漫游地图 + 选择性半透明叠层
   - 证据幕：**暗纹背景 + 文字排版 + 指数化数据可视化**（用户明确点赞的效果最佳段落）
   - 永久化/结尾幕：材质变形接力（油漆→花岗岩、折叠椅→长椅、玻璃台阶）+ 融入环境的收尾卡（半卡/半透明处理，用户点赞）
3. **插画纪录片质感**：大幅面色块、表面纹理/颗粒/排线、分层光、阴影与前景遮挡；避免连续细轮廓线、通用幻灯网格。
4. **语义精确纪律**：视觉隐喻与来源观察严格区分；指数标注（各基线独立归一）、来源归属（DOT/项目稿）、假设与评估分离；不虚构统计数据/引语/胶片档案。
5. **动画时钟**：实测旁白时钟锁定（48 cues/601.18s），每句锚定一个有意义的画面事件；无长静态保持，用渐进微动作/镜头行进/层次揭示/变形续命。

## 3. 生产管线配置（本模板的管线要求）

- codegen 必须注入完整视觉上下文：原始 topic brief + decision StepA 视觉方案 + `profile.visual.style_note`（`include_visual_context=True`；2026-10-14 已修复并有回归测试 `pipeline/tests/test_offline.py`）。缺此项会退化为模板卡片式（见 `.learnings`）。
- WEB_2D Canvas 确定性渲染契约：`window.P103 = {duration, fps, width, height, renderFrame(t)}`，无前帧依赖/无随机/无网络。
- 长片渲染超时会撞 web2d_capture.mjs 30 分钟子进程超时：确定性渲染允许"数连续已有帧→只补缺失后缀→全序列编码"的断点续渲法（`capture_resume.mjs` 模式）。
- QA 门：时长/帧方差/空帧/联系表 + 旁白逐 cue 对齐审计 + 数学口径审计（代码内 `validate()`）。
- 产物纪律：候选目录与原版目录分离，永不覆盖已验收版本。

## 4. 已验证有效（保留）

- act5 式**暗纹背景+大字排版+指数条/点阵数据可视化**——用户评价"效果最好"的信息段落形式。
- 融入式结尾卡（环境嵌入、半透明处理）。
- 材质变形接力表达"临时→永久"。
- 桌面文档舞台表达决策过程（含"教学性构造"免责角标）。
- 分格 POV + 汇聚平面表达多方立场。
- 同机位对位开场。

## 5. v1 缺陷与 v2 修复（全部已实施，实证见 runs/envpsy-case1-v2/out/qa_report.json）

1. **单底图描画通病（v1 最大缺陷）→ v2 已修**：中段改为"一句一世界"——每 cue 一个专属舞台与主导视觉事件（决策墙/道具特写/账本/挡风玻璃/路牌翻面/声波POV/三联角/站台剧场/沙漏/落牌/光斑呼吸/工具箱镜片/多时段剧场/过载减层/追光椅/同格双填/三扇门/待检命题卡/双机位对照/汇聚焦点），**全中段禁圈线箭头注解语法**。16 关键帧 VLM 盲读全部语义可辨、零描画语法。
   - 手法卡来源：[expression-bank-urban-doc-v0.md](expression-bank-urban-doc-v0.md)；可行性先经零成本手写短样片实证（`runs/v2-grammar-spike/`）再进 codegen。
   - 允许 codegen 对相邻手法做语义等价的合并转译（如延时+计数器并入多时段剧场、倒U拆成交叉路径+追光椅），验收标准是"静帧语义可辨"而非逐字执行方案。
2. **旁白书面化 + 来源标记泄漏 → v2 已修**：
   - 旁白 48 句全量口语化（第一/第二/先看/再听式连接，+16.5% 字数），TTS 全部自然语速无需加速。
   - 根因修复落在数据结构：scene JSON 的 `text`（TTS 输入）与 `sources`（机器可读来源数组）**字段级分离**（`_make_scene_v2.py`）；画面角标一律自然语言写法（"来源：NYC DOT 2010 评估"），**〔B〕〔T〕字母代号永不上屏不进语音**。
3. **表达方式未充分采用 → v2 部分补齐**：表达库 A/B/C 组手法已进入正片；继续采样扩库。

## 6. v2 沉淀的新管线纪律（生产复用必读）

1. **实测时钟流水线**：口语稿定稿 → scene JSON（text/sources 分离）→ TTS 重录（cmd_tts 自带断点续跑）→ `timing_<name>.json` → storyboard 计数行同步更新（`_make_storyboard_v2.py`）→ codegen 注入 timing。
2. **codegen 完整性三查**（sol 长响应会被 token 上限截断，2026-10-14 实录）：提取代码后必查 ①尾部 `</html>` ②`window.P103` 暴露 ③renderFrame 有 return；缺任一先手补契约尾再渲染，不必重生成。
3. **长片渲染**：直接起 node web2d_capture.mjs（自设超时>片长×0.03s/帧）；中断用 `pipeline/adapters/web2d_capture_resume.mjs`（数连续帧只补后缀，已冒烟验证）。
4. **验收门（中段专用）**：每 cue 静帧"不看旁白能说出在讲什么"+ 全段零描画语法 + 零字母角标——VLM 抽查 + 代码静态扫描（`〔[BTDS算]〕`计数=0）双通道。

# 资金周转率 v3 · 设计文档（2026-10-06，本会话 agent 亲自分步实现）

## 概念：一笔钱的循环旅程

钱是**角色**（一枚金色的币，有轻微呼吸感和拖尾），世界是一个**环形装置**——
现金 → 采购材料 → 生产 → 销售成品 → 回款 ——五个站点串成的闭合轨道。
币在轨道上跑：**跑的圈数就是周转率，跑一圈的时长就是周转天数**。
所有数字从画面里"量"出来，不从字幕里念出来。

对标语言（EXTERNAL 基准 → 设计词汇，非规则）：
- sets-not-cards：全片一个连续的"环世界"，机位在世界内运镜，不做卡片切换
- 每秒都有事件发生；一个时间窗一个焦点动作
- 结尾回收开头（币还在转，但世界已经"被理解"了）

## 色板弧线（palette arc）

- 底：墨蓝夜 #0D1420 → #101B2E 微渐变
- 主角：暖金 #E9B44C（币、轨道主笔、数字焦点）
- 辅：象牙白 #F2EDE4（文字）、青蓝 #7FB4C7（水流/流动资金层）
- **红色 #D05353 仅第 8 章出现**（不健康加速），结尾完全退场
- 全片 = 墨蓝底 × 金主角，红色是唯一一次例外脉冲

## 版式

- 1920×1080，安全边距 140px
- 环世界默认占中右（cx≈1160, cy≈560, R≈380），公式/标注落左侧带
- 字阶：章题/结论 52px 楷体系；正文标注 34px；小注 26px
- 手绘感：inkLine（hash 噪声折线）+ boil（12fps 重播种抖动）+ 币的呼吸缩放

## 工程

- 栈：WEB_2D（canvas 2D，零依赖，file:// 直载）
- 契约：window.P103 = { duration: 66.014, fps: 24, width: 1920, height: 1080, renderFrame(t) }
- 五关第 1 关：renderFrame 是 t 的纯函数，无跨帧状态，随机只用 hash(t 的离散种子)
- 章节路由：NARR 窗口表 → chapter i ∈ [starts[i], starts[i+1])，章内过渡用 ease 混合
- 复用：audio/timing_capital2.json（旁白已 AUDIT PASS）+ audio.py mux；渲染走 adapters/web2d 直连

# MOTION_SKILL.md v1 — 动画导演决策规则（语料驱动版）

适用：ClaudeAnimationBase 运行时 + patterns.js v1。分镜与代码阶段共用。
规则来源：七源语料挖掘（PATTERN_CORPUS.md）——18 条 Opus 提示词、PDoomVideo
制作级代码、edulab 教学方法论、1309 作品需求统计、官方 demo。

## A. 节奏（Rhythm）

1. **一镜一主意**：每个 shot 只讲一个 read；观众每 1.5-2.5s 只应消化一件事。
2. **重要事件后必 HOLD ≥0.5s**：相遇/命中/揭晓后用 hold() 静止一拍再继续。
3. **爆发动作必走三段**：anticipation() 蓄力→爆发→settle() 回弹；无蓄力的跳/扑一律算"突兀"。
4. **起手先世界后主角**：staggerReveal 世界元素 0.3-0.8s，主角随后入场。
5. **转场两选一**：形式转场（brushWipe/iris，颜色承接）或语义转场（主体出画入画锚定）。
   禁止无来由硬切；Out 列（转场标注）分镜必填。
6. **音乐在场必锁拍** 🆕：有配乐/固定 BPM 时用 beatCfg/beatAt 把重音落在拍上；
   每拍一事；脉冲（pulseBeat）同时打在角色 squash 与相机 zoom 上（同源同步）。
7. **待机也要呼吸** 🆕：无事件的主角保持微动（idle bob/眨眼/重心转移），
   "完全静止"只允许出现在 HOLD 拍内。

## B. 视线（Eye control）

8. **首帧主体明确**：主角占画高 ≥15%；背景勿满勿乱。
9. **冻结时刻三件套**：FREEZE_EVENT + dimOthers 聚焦 + pulseRing；相机在冻结前
   0.6s pushIn 预热；shake 只给撞击量级（amp 8-14），持续 <0.5s。
10. **遮挡即错误**：关键表情/接触点/标记物不得被遮挡；标记物揭示帧角色让位。
11. **标记物存在感**：杆高 ≥200px；起点/终点勿紧贴角色。
12. **结尾必有 payoff 帧**：静止单拍或 beforeAfter 面板，二选一或叠加。
13. **镜头永远在动** 🆕：每镜必有相机运动（推/移/跟随/微呼吸），但幅度克制
    （zoom kick ≤.03）；跟随镜头滞后主体 0.1-0.15s（前瞻感）。

## C. 教学（Teaching，MathViz 专用）

14. **数学参数块强制**：分镜声明数值（速度/时长/时刻/位置）并给推导；代码位置
    函数只用这组数。fail-closed。
15. **旁白是时钟** 🆕：一切时刻=narr().at(k,f)（第 k 句的比例处），动作窗句内
    15%-80%、时长 0.6-1.5s；绝不写死秒数。
16. **一句一动且动即推理** 🆕：每句旁白必有一个"演出推理"的动作（只出现/只闪
    =STATIC 必改）。推理→动作映射：相等→superposeCopy 叠合；求值→countUp 计数；
    验算→数值代回+标记亮起；立体↔平面→转相机不硬切。
17. **运动历史可见**：任何移动主体带 tracePath。
18. **量化读数常驻** 🆕：动态过程配 liveReadout（位置/差距/时钟实时更新）；
    关键量完成时 countUp + stampAnswer 双重确认。这正是社区成片与 Case C 两模型
    共同缺失的最大洞。
19. **语义四色绑定** 🆕：known 蓝/ask 红/aux 绿/hi 黄，图上量/板书行/结论同色；
    一个镜头内颜色不换义。
20. **视觉服从数学真值** 🆕：位置按数据计算不许目测；题目说的每个对象必画
    （漏画比难看严重）；直角必须看起来直（markRight）；答案多源一致
    （图/读数/图章/旁白）。
21. **结尾 SHOW_BEFORE_AFTER**：双主体行程对比+数字+验证拍；证明用 superposeCopy。
22. **第二主体用 creature kit**：turtle/snail/ball；颜色取 roleCol 互补色。

## D. 覆盖协议（Coverage & fallback）

23. **词表优先**：分镜从 PATTERNS.md 词表选；组合优先于新增。
24. **CUSTOM 显式声明**：词表外写 `[CUSTOM: 描述]`；代码标 `// PATTERN: CUSTOM:x`。
25. **CUSTOM 段加严审查**；**修复熔断**：同段 CUSTOM 修复连败 2 次 → 停修复，
    记缺口日志（候选新原语+变体轴），降级表达（HOLD+特写）。
26. **缺口回流**：同形状 CUSTOM 第二次出现 → 蒸馏新原语。一次性的长尾永久留自由码层。
27. **反模式清单** 🆕（社区明令禁的"AI 模板味"）：弹跳缓动、无差别粒子爆发、
    滥用辉光/镜头光晕、RGB 分离、死时间（画面无事发生的空拍）。
    我们的对应纪律：粒子只在撞击点（impactBurst）、辉光只在灵感/光效语义
    （ideaBlow/glow）、缓动只用库曲线。
28. **环境应变当秤** 🆕：重量/速度/尺度优先画在环境反应上（凹陷、裂缝、痕迹、
    参照物变形），不靠主体自身缩放表达。
29. **强制推理档**：所有模型 reasoning 全开（GLM 默认 max；Luna
    reasoning_effort=high）。
30. **两段式交付**：storyboard → code 分开调用；大代码一次生成（max_tokens 65536，
    temp 1.0）；运输层错误 60s 退避重试，全量 prompt 有缓存。

```
每镜铁律: something happens / 情绪永不瞬变 / 主体占帧高 40% / 相机永远在动
```

## 2. 课程定位

**书名**：《设计基础：观察、构成与微空间建造》

这门课不是“三大构成”复习课，也不是软件培训。它把环境设计的基础能力组织成一条链：

> 看见 → 记录 → 抽象 → 组织 → 围合 → 身体检验 → 材料与光 → 建造 → 表达 → 综合

贯穿项目是青岚大学北门西侧一块 **6m×9m、54㎡** 的校园边界灰空间。学生要在 12 章中逐步完成现场观察、形态抽象、秩序组织、空间模型、身体测试、材料与节点、光色测试、建造原型、A3 表达与终期答辩。

课程按 **96 学时总量**设计：48 课内学时（16 讲授 + 32 工作坊）+ 48 课外学时。教师手册另给 32 学时紧凑版与 64 学时扩展版。

## 3. 学生用书结构

| 阶段 | 章节 | 核心问题 | 阶段产物 |
|---|---|---|---|
| 一、看见与记录 | 第1—2章 | 我到底看见了什么，别人能复核吗 | 现场初记、行为地图、观察档案 |
| 二、抽象与秩序 | 第3—4章 | 从现场提取什么，怎样组织 | 12 张形态抽象图、6 组秩序变体 |
| 三、空间与身体 | 第5—6章 | 人怎么进、怎么停、怎么转身 | 3 个 1:50 模型、1:1 身体测试 |
| 四、材料、光、色与建造 | 第7—10章 | 它用什么做，怎么站住，白天黑夜怎么变 | 材料板、节点样品、光日记、结构模型 |
| 五、表达与综合 | 第11—12章 | 怎样让别人看懂并相信你的决定 | A3 设计板、3 分钟陈述、最终方案包 |

每章统一体例：

- 开篇故事；
- 本章要解决什么；
- 4—6 个设问小节；
- 至少一个“算给你看”；
- 先例卡（可学什么 / 不可抄什么）；
- 想一想（A 型）；
- 实践任务卡（B 型）；
- 本章小结；
- 尾注；
- 本章配图（5—8 幅，统一图注含图号、图名、类型与数据标签）。

## 5. 配图技术路径

采用与《商业空间设计》相同的“矢量组件优先”流程：

1. **组件库**：`_tools/envfiglib.py` 提供画布、文字、卡片、人物、树、坐凳、雨、尺寸线、指北针、相机等统一图元。
2. **模板渲染**：`_tools/make_env_figures.py` 按图号选择场景、流程、对照、平面、剖面、轴测、版式、矩阵、时间轴、图表、照片位等模板。
3. **矢量源文件**：每幅图输出 `_figs_v1/svg/figX-Y.svg`，画布 1600×1000，章节有独立强调色。
4. **高清导出**：`_tools/export_env_figs.js` 用 `sharp` 以 3200 px 宽导出 PNG，供审阅与后续排版。
5. **视觉 QA**：生成 4 张 contact sheet，逐图检查节点数量、文字溢出、卡片压图、尺寸链、图注匹配。
6. **入库**：`_tools/finalize_manifest.py` 生成 83 条交付清单，登记尺寸、数据标签、版权与 SHA256。
7. **插入 DOCX**：`_tools/integrate_figures.py` 把每章配图统一放在“本章配图”图集；`_tools/_md2docx.py` 自动生成 1600 px、质量 84 的 JPEG 缓存，避免 DOCX 过大。

本课程 83 幅图全部为原创矢量示意图，不含第三方图片、AI 效果图或未授权照片。若后续加入模型照片、现场照片或先例图片，须逐张登记来源与授权。

## 7. 数据与版权边界

本书使用四类数据标注：

- **已核实**：有明确来源，可复核；
- **教学常用值**：行业或教学常用参考值，会因地区、材料、产品、人群变化；
- **教学假设**：为课程练习构造的场地、人物、行为、预算或数据；
- **须核验**：必须通过现场测量、产品资料、现行标准或专业审查确认。

北门场地、青岚大学、人物、行为计数、面积、预算、材料价格、光照与使用情境，除特别注明外均为**教学假设**。涉及结构、消防、电气、给排水、无障碍、树根保护与场地许可，统一写“**须专业核验**”，不下合规结论。

书中先例卡只做文字分析，不复制受版权保护的图片、图纸或教材正文。83 幅配图均为课程组代码生成的原创矢量示意图，可作为教学审阅版使用；正式出版前仍须完成专业审读与最终印刷色彩校验。

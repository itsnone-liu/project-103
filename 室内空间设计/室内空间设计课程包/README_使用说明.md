## 旧版首轮试教方法（仅对应v0.1；v0.2暂勿照此执行）

- 学生读教材第4章，教师解释功能邻接矩阵与设计冲突。
- 学生打开HTML实验，在给定空间中布置工作桌、座椅与交流区，保存A。
- 学生主动修改布局形成B，比较家具冲突、入口示意干扰、工作桌靠窗比例等指标。
- 学生导出两个方案的JSON及平面图片，完成200–300字评价：谁获益、谁受影响、模型没有覆盖什么？
- 教师只把自动反馈当作证据辅助，重心放在功能解释、行为与体验的设计论证上。

## 明确限制

- 本HTML实验已完成静态代码语法检查，尚未完成真实班级可用性测试和浏览器端到端自动化回归。
- HTML只提供二维家具占位与启发式评分；不包含真实三维照明计算、准确通行净宽或国家标准条文判定。
- “家具无交叠”不等于“通道无障碍”或“疏散符合消防要求”。
- 本教材试编本是首轮课程内容，不包含可直接出版所需的完整案例图版权与规范逐条审查。

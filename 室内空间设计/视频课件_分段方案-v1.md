## 一、课程定位对分段的影响

这门课与现代设计史的本质差异（用户定调）：**它是空间分析与处理课，不是史实叙事课**，且**贯穿案例（U90 沈家）**横跨全程。因此：

1. 段落的主体不是"讲一件事"，而是"做一个空间决策并展示其后果"——每段视频 = 提出空间问题 → 分析工具 → 决策 → 后果对比（A/B）；
2. U90 冻结几何（户型库）是全课程唯一的案例数据源，所有段涉及沈家的画面必须用同一套冻结数据，不另编户型；
3. 教材自带 fig SVG（fig1-1～fig12-1）优先复用为画面母题，演绎重绘时保持与教材图同一套线型/字阶；
4. 每章实践任务卡对应的线上实验（L03/L04/L04K/L06…）在片尾以"课后可玩"卡收口，视频（理论主线）与实验（验证层）互链。

## 六、awesome 调研：空间分析课的视频形态适配（2026-10-20）

外部检索结论（来源见方案讨论记录），四种形态可借，一种不采：

1. **笔迹跟随解说（khan-explainer 式，haiderfarooq3/khan-explainer）**：笔边画边讲、逐笔生长。适配 S3 尺度人体——尺度线/通行带/包络线随旁白**逐笔画出**而非淡入，"标注是手写出来的"与尺度课的气质一致。机制=确定性 stroke 生长（等价 renderFrame(t) 内按句进度推进 dashoffset），不违反纯函数合同。
2. **平面→空间展开（casa-serra 式 morph，Sam1983Aing/casa-serra）**：平面图随进度抬升成体量。适配 S5/S6——U90 冻结平面上做完二维分析后，镜头把墙"立起来"看空间后果；这正好把本课"分析在平面、后果在空间"的核心动作变成镜头语言。实现与仓内 L06 双档渲染层（three.js r147 已自托管）同源，3D 镜头可复用该资产。
3. **数据生长动画（3b1b/manim 语法）**：S2 图表演绎的既有语法（矩阵逐格点亮、动线渐次画出），dh 批已验证，直接继承。
4. **同构开源管线佐证（junjie721/canvas-explainer-videos、xdis/opus-video-studio）**：单 Canvas HTML 逐帧 + TTS + ffmpeg 与 103 产线同构，证明路线成熟；opus-video-studio 的 Three.js/Blender 层为将来 S5 段落升级 3D 镜头留了参照。
5. **不采**：写实 AI 视频管线（Wan2.2/FLUX 类）做教学内容——违反教学确定性纪律；真实影像素材——无授权来源。写实镜头仅限教师演示用途，不进课件段。

对分段方案的落地修正：S3 类型全段采用"笔迹跟随"作为默认入场机制；S5/S6 类型在"分析→后果"转折点采用一次"平面抬升"运镜（每段至多一次，避免滥用）；其余类型维持 dh 视觉纪律 v1。

## 七、用户裁定记录（2026-10-20，v1 定稿）

1. **教材 SVG 形象化升级**：教材 fig*.svg 不做"原样内嵌"，视频里必须**升级重绘**——保留母题与线型语汇，但更形象具体：家具画成家具、人形画成人体、材质有质感、光有方向；原图只在对证位（"教材图 3-2"角标）出现。
2. **时长放宽**：不严格 300s 下限。正文目标 280–320s，**门禁下限 270s**（4.5 分钟）；字数预算相应 1200–1450 字。
3. **空间课特点强制条款**（写进 profile 硬纪律）：空间设计≠历史/理论课——每个正文段**至少一次可见的空间状态变化**（墙/隔断移动、布局切换、参数滑动看后果、A/B 同框对比），旁白为空间操作服务；纯静态讲解连续不得超过 3 句。
4. 其他照 v1 执行：54 段规模、龙小淳、CA-3 小户型专题保留、种子片＝3.2＋4.2。

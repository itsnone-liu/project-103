# ISD-L04K 厨房工作站与折返计数 · 实现简报（v1）

目标：一个面向本科环境设计二年级的**动画游戏型**教学实验网页。学生拖动厨房工作站，实时看到"工作三角"连线与教学区间校验；点"模拟四菜一汤"，一个小人动画沿任务路径走完全程，折返计数器跳动计分。学生在优化挑战中体会教材第7章的核心结论：**消除高频环节间的障碍，比追求总步数更重要；每天十次的折返，胜过每年十次的绕路。**

## 1. 页面结构（单屏三栏，1920×1080 设计，自适应）

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏：实验名 + 教学定位（第7章）+ "教学常用值，非国家标准"常驻角标 │
├──────────────────────┬─────────────────────────────────────┤
│ 左：画布区（SVG）      │ 右：面板区（三段，可滚动）              │
│  厨房平面 2.8×2.25m   │  ① 任务卡与得分（折返/步行距离/三角）    │
│  可拖工作站+固定项     │  ② 三层反馈：观察 / 规则建议 / 教师判断  │
│  播放时小人动画       │  ③ A/B 版本 + 导出（JSON/PNG/对比报告） │
└──────────────────────┴─────────────────────────────────────┘
```

## 2. 场景与几何（坐标契约：origin=西北角，x向东，y向南，单位米，物件中心点定位）

房间 2.8m×2.25m。SVG 画布：1m=140px，房间居中，四周留白放尺寸标注。

**固定项（不可拖，深灰填充+斜线纹理，右上角小字"固定"）**：
- 烟道：西墙 y=0.15–0.75（600×600mm 角部方块）
- 排水立管：西墙 y=1.4（200mm 圆）
- 阳台门：北墙 x=1.9–2.65（墙线断开+门弧虚线）

**可拖工作站（家具俯视符号，教材图7-1/7-2制图风格）**：

| id | 名称 | 尺寸(宽×深,m) | 符号画法 | 锚定规则 |
|---|---|---|---|---|
| fridge | 冰箱 | 0.6×0.65 | 矩形+对角细线+"冰箱" | 自由（任意位置，含非贴墙） |
| sink | 水槽段 | 0.8×0.6 | 台面矩形+内椭圆+龙头点 | 吸附墙面（贴墙时台面沿墙展开0.8宽，深度0.6朝内） |
| stove | 灶台段 | 0.75×0.6 | 台面矩形+两个同心圆（灶眼） | 吸附墙面 |
| prep | 备餐台面 | 1.0×0.6 | 双线边台面（外框+内框线距4px） | 吸附墙面 |
| trash | 垃圾桶 | 0.35×0.35 | 小方+叉线 | 自由 |

吸附：拖动松手时若工作站中心距任一墙<0.35m，则贴墙对齐（旋转为沿墙方向），带 150ms 缓动动画；否则保持自由位（此时台面画为"岛式"方向，默认水平）。冰箱/垃圾桶不吸附。

碰撞：矩形相交检测（AABB，旋转只有0°/90°两态所以AABB够用）；相交对高亮红色描边并在"观察"层报数。越界（中心出房间或矩形出墙）报数并红色半透明回弹到最后合法位。

## 3. 规则引擎（纯函数，与渲染完全分离；同输入同输出）

```js
// evaluate(scene) -> report（全部数值保留2位小数）
// scene: {objects: {id: {x, y, rot}}}
report = {
  workTriangle: {legs: [d(fridge,sink), d(sink,stove), d(stove,fridge)],
                 total, legRange: [1.2, 2.7], totalRange: [4.0, 6.6]},  // 教学常用值
  aisle: {minClearance},      // 台面前缘到对面墙/另一台面前缘的最小净距
  errand: {moveCount, walkDistanceM, handsFullMoves},   // 见任务模拟
  collisions: {pairCount, pairs: [...]}, outOfRoom: {count}
}
```

距离 d 取两站**使用中心**（符号几何中心）。三角连线画淡蓝细线+三边长度标注（米）。

**任务模拟（确定性动画，非随机）**："四菜一汤·晚餐备餐"，**执行策略由冰箱到操作链的距离决定**——这正是教材图7-1的教学点：
- **一次取齐模式**：冰箱使用中心到最近操作台（水槽/备餐）端点距离≤1.0m → 序列 `[fridge,sink,prep,stove,trash]`；
- **分批处理模式**：>1.0m → 序列 `[fridge,sink,prep]×3 + [stove,trash]`（三趟往返拎食材）；
- **连续作业链**：sink/prep/stove 同墙且首尾间隙≤0.05m 构成一条链；**链内相邻步进不记移动、不计距离**（转身即达）；链断裂则每段照记。
- 计数：相邻两步站点不同（且不属于同一链内步进）记 moveCount+1；walkDistance 累加站间直线距离；**handsFullMoves** 单列——每趟 fridge→链首段与 stove→trash 段（教材："标记双手被占用的操作"）。
- **验收锚点（自检断言，必须成立）**：基线A（冰箱对侧+链连续）moveCount=6、walkDistance≈图7-1甲量级；基线B（冰箱贴链+链连续）moveCount=2。若你的实现算不出这两个数，说明规则实现有误，不要改断言。

动画：一个小圆头+身体的小人符号（教材风格：无脸、深灰描边）沿折线路径匀速移动（0.8m/s），路径暖橙色虚线留下轨迹；每完成一段，右上得分卡对应数字跳动+1（scale弹跳动画）。动画可暂停/重放/倍速(1x/2x)。

**开局关卡（游戏化）**：
- 关卡1"诊断"：载入基线A（冰箱在西墙对侧/东墙，操作链沿北墙）——预期 moveCount≈6；学生先跑一次模拟看到坏结果。
- 关卡2"处方"：自由布局，目标 moveCount≤3 且三角边长全部落入教学区间；达标时得分卡出现绿色"✓ 达成"并解锁"挑战模式"（附加：aisle≥1.0m 且碰撞=0 的三星评价）。
- 关卡切换用顶部胶囊按钮；关卡2可随时"重置为基线A"。

## 4. 三层反馈（任务书§9红线：三层分列显示，禁止合成"AI总分"）

- **观察（客观）**：三角三边与总长、通道最小净距、折返次数、步行距离、双手占用移动数、碰撞对数、越界数——纯几何事实，无形容词。
- **规则建议（启发式）**：每条前缀"教学常用值提示："。例：「水槽—灶台边长2.9m，超出教学常用区间1.2–2.7m——工作站间距可能过长」；「折返4次：比基线A(6次)少2次；教材示例乙方案为2次」。绝不说"不符合规范/不达标"。
- **教师判断（占位）**：灰底框列出3个人工评议维度（多人协作可能性/中餐烹饪与烟道关系/取舍依据），附"由教师课后评议"说明。

## 5. A/B 版本与导出

- 「存为A版」「存为B版」两个快照按钮；存好后在面板显示两版关键指标对照表（moveCount/总步行/三角总长/最小通道），差异项高亮。快照为深拷贝，后续拖动不得原地修改已存版本（任务书引擎门禁）。
- 导出三件：`project.json`（schema 见下）、`plan_png`（canvas或SVG序列化下载）、`comparison_report.json`（A/B对照+当时规则版本号）。
- 导入 project.json 恢复场景（导出→导入等价，门禁）。

## 7. 质量门禁（实现后自检，全部满足）

1. 零输入可玩：打开即是关卡1完整可用状态。
2. 拖不出房间；碰撞高亮；临界接触（恰好相切）不误报。
3. 快照后继续拖动，A/B数据不变。
4. 导出→导入→再导出，两份 JSON 字节等价（savedAt 除外）。
5. 窗口缩放/高分屏不产生几何漂移（SVG viewBox 驱动，米制为唯一真值）。
6. `window.__LAB_SELFTEST__()`（控制台可调）跑6条断言：基线A的moveCount=6、基线B(预置好隐藏函数可载入)的moveCount=2、三角区间判定、碰撞检测、快照隔离、导出导入等价；返回 {passed: n, failed: [...]}。
7. 无 console 报错；requestAnimationFrame 动画在标签页隐藏时暂停。

## 8. 教学文案（页面内固定文案，逐字使用）

- 开场引导（关卡1顶部横幅）：「腊月二十九的下午，沈太太掌勺，沈先生进门放菜要洗鱼，祖母端着肉馅想找块台面——三个人不是被"面积"绊住，而是被"作业面"绊住。先跑一次模拟，看看这间厨房为什么要跑六趟。」
- 关卡2引导：「拖动工作站，让"四菜一汤"少跑几趟。目标：折返≤3次，且工作三角三边都在教学区间内。想一想：每天十次的折返，和每年十次的绕路，哪个更要紧？」
- 页脚：「数据：U90厨房2.8×2.25m为教材教学假设；工作三角与通道数值为教学常用值。交互实验对应《室内空间设计》v0.4 第7章实践任务卡。」

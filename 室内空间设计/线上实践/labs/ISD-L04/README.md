# ISD-L04 U90全户型功能组织与动线冲突

《室内空间设计》v0.4 第4章配套线上实践（Level A：单文件网页，无后端、无外部依赖、平台无关）。
对应教材：4.2 邻接矩阵；4.3 动线四条与交叉点；4.4 固定约束三色法；4.5 方案A/B与失效条件；实践任务卡"U90两版布局"＝全书核心成果②。
前置：`住宅贯穿案例与户型库 v0.1` U90「青枫里2栋1单元401」+ 沈家四口 + 情境卡A/B。

## 为什么这个实验更"像真实设计任务"

- 不是自由画布：承重墙×2、主卫/公卫降板、烟道/排水/燃气立管、门窗洞口全部冻结（红色·不可改）；学生的设计杠杆是**功能重组**（书房三模式/储物区四模式/工作位三选/烘焙位/门位槽位/家具）——教材4.4"在固定约束里做设计"。
- 多住户多目标：沈家四口各自需求（办公/备课/学习/照护）进入邻接矩阵、时段占用表与早高峰离散事件模拟；指标分列呈现，**永不合成总分**。
- 情境切换：现状A vs 五年后B（祖母常住、女儿12岁、办公上升）——教材4.5"情境一变，优先级反转"。
- 核心产出 = 方案A（办公优先）/方案B（照护优先）对比 + 各自"失效条件"陈述（不评分，随导出归档）。

## 使用

- **学生/试教**：双击 `unit_lab.html`。关卡1载入基线A（办公优先）诊断冲突；关卡2自由重组；保存A/B两版并各写≥20字失效条件后解锁"对比叙事"视图。
- **本机QA**：`D:/ComfyUI_windows_portable/python_embeded/python.exe qa_run.py`。通过标准：`"pass": true`（selftest 8/8 + B夜起<A + 确定性）。

## 教学规则要点（全部为教学常用值/课堂讨论工具，非国家标准）

- 邻接矩阵7条（+2…−1五档）随格标注证据来源（访谈/观察/课程假设）；引擎逐条判 满足/违背/不适用——"矩阵只摆冲突，不替你裁决"。
- 四条动线（日常/访客/家务/夜起）= 房间中心+门中点的最短路折线（教学简化，非寻路）；交叉计数两两计算；门位槽位改变路由与交叉。
- 早高峰7:00–7:30离散事件模拟（10s步长，确定性）：卫生间占用/排队、走廊让行事件；0.8m/s。
- 时段冲突矩阵：先生视讯/周六加班、太太备课、全家晚餐、女儿学习/游戏、祖母睡眠/电视、周末访客——"平面几何看不出的风险"。
- bed_fold_count：双模式床=2次/日（晨收晚展），固定床=0（照护稳定度代理指标）。

## 数据与复现

- 平面为**拼合教学假设v1**：户型库明言"尺寸加总不等于可无冲突拼接"，本图锚定房间表面积（8间±2%自检断言）；边界/过渡带为教学假设，非施工图。
- 坐标契约：origin=西北角内墙角，x东y南，单位米。
- 确定性：同 state JSON 必得同 report（qa 断言两次 evaluate 等价）。
- 页内 `window.__LAB_SELFTEST__()` 控制台可调（8断言）；`window.U90Engine` 纯函数引擎供教学复用。

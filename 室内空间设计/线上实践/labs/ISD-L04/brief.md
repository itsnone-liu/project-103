# ISD-L04 实现简报（sol 高推理单文件实现）

产出 `unit_lab.html`：一个自包含 HTML（内联 CSS/JS，零依赖，file:// 与静态服务器均可运行）。这是本科生《室内空间设计》第4章配套复杂设计实验：学生**不是自由画墙**，而是在冻结的 U90 户型（承重墙/降板/管线固定）内重组功能模式、门位与家具，引擎确定性计算邻接矩阵、四条动线、早高峰多人离散事件模拟与时段冲突，A/B 两版对比并撰写"失效条件"。所有数值为教学常用值/课堂讨论工具，**页面必须明示非国家标准**。

## 0 全局纪律（违反即废）

1. 确定性：同一 state JSON → 同一 report JSON（无 Date.now/Math.random 参与计算；动画只用性能时间做插值显示）。
2. 三层反馈分离：观察（客观测量）/ 规则建议（前缀"教学常用值·讨论工具"）/ 教师判断（静态提示，不自动评分）。**绝不合成总分**。
3. 纯函数引擎 `window.U90Engine`（evaluate/baseline/taskPlan 等全纯函数），渲染层只调用不计算。
4. UI 全简体中文，Microsoft YaHei，字号≥12px。视觉=教材制图风：白底、2–3px 黑线框、房间浅色填充、承重墙粗红、动线彩色虚线。
5. 代码紧凑：CSS≤4k 字符（复用类），JS 短命名+共享 helper，注释只留分节标记。总文件目标≤58k 字符。
6. 坐标单位米，origin=西北角内墙角，x东 y南。画布 viewBox="-0.4 -1.4 12.0 13.4"，比例 56px/m（SVG 内部仍用米，外层 scale(56)）。

## 3 UI 结构

顶栏：标题"U90全户型功能组织与动线冲突"+副题（教材锚点）+徽标"全部为教学假设/课堂讨论工具，非国家标准"。导航按钮：关卡1·诊断 / 关卡2·处方 / 挑战·对比叙事(禁用) / 载入方案A / 载入方案B / 重置为基线A。情境A/B 切换开关（B=五年后为设计对象）。

左栏：①「功能重组」五组分段选择器（study_mode/storage_mode/work_pos/bake_pos/closet_mode，中文标签+当前模式说明一行）；②「门位（可讨论）」五樘门各一行：门名+当前槽名+【换槽】按钮；③「已选家具」坐标输入+应用+删除提示（副本不支持，家具集由模式决定）；④提示：拖拽限本房间，方向键微调。

中栏：SVG 平面（房间分区填充：公区暖米#f7f1e3/私区淡蓝灰#e8edf2/家务淡绿#e9f2e8/走廊浅灰；房间名+面积标签≥12px）。下方：动线叠加四开关+「早高峰模拟」播放器（播放/暂停/倍速/滑杆）+事件滚动列表。

右栏三卡：①「邻接矩阵」7行表（对/赋值chip：+2绿+1浅绿0灰−1橙−2红/状态/证据来源），底部一句"矩阵只摆冲突，不替你裁决"（教材4.2）；②「三层反馈」：观察=facts dl（四动线长/交叉数/夜起/早高峰冲突+排队/时段冲突对数/翻折/碰撞）；规则建议=ul（逐条"教学常用值·讨论工具"前缀：如夜起>9m 建议东槽/老人房模式、时段冲突非零提示写失效条件、洗衣laundry模式提示晾晒代价）；教师判断=静态列表（私密性/照护负担/协商机制/方案讲述）+灰色"课后评议，不自动评分"；③「A/B版本与失效条件」：存为A版/载入A版/存为B版/载入B版；对比表（两列：A/B 全指标并排，差异行浅橙）；两个 textarea（A版失效条件/B版失效条件，占位示例"当______时本方案失效：______"）；导出工程JSON/平面PNG/对比报告JSON（含规则版本+失效条件文本）。

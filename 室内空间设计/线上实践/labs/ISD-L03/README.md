# ISD-L03 居住需求档案与气泡图任务书

《室内空间设计》v0.4 第2章配套线上实践（Level A：单文件网页，无后端、无外部依赖）。
对应教材：第2章 需求档案与任务书；4.2 邻接五档。前置：`住宅贯穿案例与户型库 v0.1` 沈家四口访谈要点 + 情境卡A/B。

## 设计思想（对标研究结论的落地）

气泡图是"需求→几何"之间的中间表征。本实验把**关系本身变成设计对象**：
学生把功能气泡（带面积权重+时段占用）装进 U90 冻结房间槽、在气泡间连五档邻接边并挂证据标签，
引擎做**白盒逻辑检查**（面积超载/时段冲突/三角张力/区带错配/访谈覆盖/平面对表），
A/B 两情境各存一版、写失效条件、导出"气泡图任务书"（isd-design-v1 扩展：`bubbles[]/edges[]`）。

与 Graph2Plan 的分界：它用图生成平面（模型替人设计）；我们用图**论证设计**——图是学生的推理记录
（主张+证据+时段），引擎只摆冲突、永不生成平面、永不合成总分。导出的任务书可作为 ISD-L04 的前置输入。

## 使用

- **学生/试教**：双击 `bubble_lab.html`。关卡1 载入现状装填诊断冲突（play↔guest 周六同槽）；关卡2 自由重装+连边+挂证据；情境A→B 新增祖母气泡（老人睡眠+茶歇照护+夜起边），看 delta、写两版失效条件（各≥20字）后解锁任务书导出。
- **本机QA**：`D:/ComfyUI_windows_portable/python_embeded/python.exe qa_run.py`。通过标准 `"pass": true`（selftest 8/8 + 基线A 超载0/时段冲突恰1 + 确定性）。

## 教学规则要点（全部为教学常用值/课堂讨论工具，非国家标准）

- 面积超载阈值 105%（教学假设）；时段冲突按日别（每日∩周六=同日）与跨午夜处理。
- 三角张力=同组气泡内档位极差≥4 且含正负主张（"必须紧邻"不可传递）。
- 区带错配：私↔公/家务=红，半私↔家务=黄。
- 访谈覆盖：14 条要点逐条核对；引用当前情境不存在对象的=留待情境B（不算遗漏）。
- 对表：边档位 vs 冻结平面邻接事实等级（same_room5/open·door4/corridor·adjustable3/fixed_wall2/far1），差1级=部分满足。

## 二、视频类型清单（5 类）

从教材真实内容形态归纳，替代上轮预分类中的"环境因素专题型"（实际体量 <5%，并入 T1）：

### T1 概念图解型（主力，约 55-60%）
- **定义**：把一个抽象概念 / 理论 / 分类结构变成可视图解。两个子型：**结构图解**（静态结构动起来：分类树、维度模型、矩阵）与**机制演示**（动态因果链：感觉→知觉→认知流水线、应激过程）。
- **视觉语言**：图形符号 + 关系动画 + 少量实景贴片；一个"锚定比喻场景"开场（如人际距离=气泡）。
- **教材素材**：格式塔组织规律、生态知觉"提供"、适应水平三态、情绪三因子、认知地图五要素、场所依恋维度、应激过程模型、习得性无助、人际距离四段、私密性层次、领域三类、拥挤三解释、前景—庇护所、ART 四属性、偏爱矩阵、建筑三论、协调/宽敞/围合感……
- **参考锚点**：《从细胞到量子场的缩放动画之旅》（1:47，完整 prompt，结构/尺度图解范式）
- **互动位**：参数滑块 / 模拟器（人际距离演示器、偏爱矩阵评分器、复杂性滑杆）

### T2 案例解析型（次主力，约 15-20%）
- **定义**：真实场所 / 调查案例的叙事 + 解读，"看片学结论"。含场所考察（卫城、海淀镇、成都茶馆）与实验案例（感觉剥夺、婴儿视觉剥夺）两个子型。
- **视觉语言**：场景图 / 地图 / 照片素材 + 标注动画 + 数据可视化；叙事线 = 现象 → 观察 → 解释 → 设计启示。
- **教材素材**：绪论卫城祭祀、海淀镇/台北/汉正街意象、空间句法实例、场景复兴实例、声景三实例、深圳中心书城、成都茶馆、乐山茶馆、感觉剥夺实验……
- **参考锚点**：《中国建筑史知识点讲解》（1:35，无 prompt——sol 直接分析视频本身，不依赖原 prompt）
- **互动位**：热点点击（场所图上点开注释）、地图 scrub

### T3 学科史叙事型（约 5%）
- **定义**：时间轴叙事，讲"这门学问怎么来的"。绪论 1 片 + 个别理论沿革（如第七章第一节人类进化史）。
- **视觉语言**：年代轴推进 + 人物/事件卡 + 风格化场景插画。
- **参考锚点**：《AI 发展史纪录短片》（3:00，完整 prompt——质量标杆；复现难度已定调偏高，只借其叙事节奏，不追其制作密度）
- **互动位**：时间轴 scrub、事件卡翻转

### T4 方法演示型（约 5%）
- **定义**：教"怎么做研究"。第八章第一节（专家/受众评价系统、SBE 法、语义差分）+ 第九章第一节（五 W 法、行为观察四式、行为痕迹推测）。
- **视觉语言**：操作流程演示 + 界面模拟 + "假想研究" walkthrough。
- **参考锚点**：《交互式相机对焦光学实验室》（0:32，交互演示型）
- **互动位**：模拟操作（亲手做一次 SBE 评价 / 设计一份行为观察记录表）

### T5 章节总结型（约 15%，模板化衍生）
- **定义**：章末 recap（10 章 ×1）+ 全课总结（×1）。素材全部来自本章已产出的视频，低成本模板化。
- **视觉语言**：知识卡回顾 + 章内概念关系图（每章一张"概念地图"终帧）。
- **参考锚点**：无外部参考，模板自建。
- **互动位**：章测验（3-5 题快检）

## 三·五、单片时长（v1.1，**已被 §〇 v2 裁决覆盖：标准 5min/片，保留作推导过程参考**）

依据三个约束：①103 现有管线 `produce.py` 强制 8–12 句旁白（中文 TTS ≈4–4.5 字/秒，每句 20–30 字）→ 天然 40–90s 体量；②Opus 参考片区讲解类 1:00–2:08；③单片只承载 1 主概念 + 2–4 支撑点（种子-扩散粒度，不做全文朗读）。

| 类型 | 单片时长 | 旁白句数 | 说明 |
|---|---|---|---|
| T1 概念图解 | **60–90s** | 8–12 句 | 正好对齐现有 8–12 句旁白管线 |
| T2 案例解析 | **90–120s** | 12–16 句 | 叙事铺垫需要额外 2–3 句 |
| T3 学科史叙事 | **2–3min** | 20–30 句 | 时间轴叙事，AI发展史 3:00 为锚 |
| T4 方法演示 | **90–120s** | 12–16 句 | 操作 walkthrough |
| T5 章末总结 | **60–90s** | 8–12 句 | 回顾节奏快，句短 |

**全课总量级**：核心 ~45 片 ≈ 50–55 分钟 + recap 11 片 ≈ 12–15 分钟 → **全课 1 小时上下**（正常网课体量）。

⚠️ 时长与粒度联动：一节 7–13k 字教材塞不进一个 75 秒的片——"一片 = 该节核心概念精华"，不是全文朗读。若要更高内容覆盖，要么单片拉长到 120–180s（B 站式精讲），要么一节拆更多片（片数上探 80+）。

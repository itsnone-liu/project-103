# Remotion Textbook-to-Video Spike 01 — Review

## 1. 如何把教材压缩成约 30 秒

保留原文的完整因果链，但不逐句把教材抄到屏幕：旁白约 29.2 秒，900 帧（30 fps，共 30 秒）。把内容压缩为四个连续建立的认知阶段：受热差异 → 暖空气上升与低压 → 近地面海风 → 高空返回并闭环。画面保持同一海岸剖面，避免每个概念切换成互不相关的 PPT 页。

## 2. 选择的 scene 及原因

1. **0–5.6 s：同样日照，不同升温速度。** 同屏比较海洋“升温较慢”和陆地“升温更快”，陆地增加暖色热晕。
2. **5.6–12.8 s：陆地暖空气上升，近地面低压。** 暖色空气团沿上升箭头移动，再出现陆地低压、海面高压。
3. **12.8–21.3 s：近地面海洋高压流向陆地低压。** 蓝色动态箭头跨过海岸，并在学生理解方向后揭示名称“海风”。
4. **21.3–30 s：高空气流返回海洋并下沉。** 紫色回流箭头与此前上升、近地面流动连接，最后命名“闭合的热力环流”。

这四段不是四张独立幻灯片，而是同一个空间模型逐层增加信息。

## 3. 动画与旁白的分工

- **主要靠动画：** 海陆位置、陆地热晕、暖空气上升、海陆高低压的空间位置、近地面海→陆、高空陆→海以及环流闭合。
- **主要靠旁白：** “为什么”——陆地升温更快、空气受热膨胀上升、近地面气压随之降低、空气从相对高压流向相对低压。
- **屏幕文字：** 只保留短标签与逐步点亮的因果链；字幕承担无障碍和听觉确认，不把整段教材一次性铺满屏幕。

## 4. 为什么选择当前视觉技术

使用 Remotion + React/TypeScript + 内联 SVG + CSS：

- Remotion 统一帧级时间线、音频、字幕和 MP4 渲染；
- SVG 适合海岸剖面、气流路径、箭头和标签，方向可以精确审查；
- CSS 负责排版、色彩、信息层级；
- 无需 Canvas，因为对象数量少、没有粒子级模拟；
- 未使用 Manim，因为没有公式排版或需要数学对象变换的内容，Manim 不会提升本题教学效果，反而增加双渲染链复杂度。

## 5. 首次版本及问题

首次完整实现保存在 `attempt-1/`，在首次完整 render 前冻结。它成功生成 1920×1080、30 fps、30 秒、带中文 TTS 和字幕的 MP4。TypeScript 检查通过。

首次 render 前出现两个生产环境问题：PowerShell 生成的 `package.json` 含 UTF-8 BOM，Webpack JSON 解析失败；两个并行首次 Remotion 任务同时下载 Headless Chrome，截图任务发生临时 zip 竞争。去除 BOM，并在浏览器下载完成后串行运行，render 成功。这些是运行基础设施修复，不改变视频教学设计。

四个代表帧检查后，首次内容没有方向性事实错误：陆地升温快、陆地上升、近地面海→陆、高空陆→海均正确。但存在以下实质呈现问题：

1. 最终闭环虽然已有海上方下沉箭头，但路径衔接和“下沉”语义不够强，容易被看成三段分离箭头；
2. 低压/高压标签和陆地/海洋大字在部分阶段距离较近；
3. 底部五步因果条离字幕较近，同时一次显示五项，造成字幕区信息偏密；
4. 管状气流使用虚线移动，但箭头头部与虚线动画可能在单帧截图中造成方向误读，需要加强固定方向提示；
5. 外部 Google Fonts 导入不符合完全自包含/离线稳定目标，应删除。

VLM 曾把实际向上的红箭头误判为向下，也曾把正确的 `+50/120 L` 类截图文字误读；因此视觉模型意见只作为线索，方向以 SVG 路径、marker 终点和多帧状态为准。

## 6. 唯一一轮集中 repair

最终版一次性完成：

1. 将三段回流路径改成端点更明确的连续环路，并在海上方增加“空气下沉”标签；
2. 加强固定箭头头部和路径连接，使动态 dash 只表达流动，不承担方向识别；
3. 调整高低压、海陆标签的位置，减少遮挡；
4. 精简底部因果条，在当前阶段逐项出现并抬高字幕安全区；
5. 删除 Google Fonts 外链，改为系统中文字体栈；
6. 保持原旁白与 29.2 秒 TTS，不增加教材外的新事实。

## 7. 最终视频是否忠实教材

是。最终版保持：白天陆地升温更快；陆地暖空气上升；陆地近地面相对低压、海面近地面相对高压；近地面由海洋流向陆地形成海风；高空由陆地返回海洋，并在海上方下沉形成闭合环流。没有加入与教材冲突的海陆风昼夜反转、科氏力或复杂天气背景。

## 8. 相比“教材文字 + PPT + 配音”的教学价值

学生看到的不是一句话对应一张图标，而是同一空间中的状态累积：陆地先变暖，空气团实际上升，原位置出现低压；海面高压与陆地低压同时留在画面上，然后近地面箭头从高压跨海岸指向低压；最后高空回流与下沉把此前动作连成闭环。因果、方向、层次和时间顺序共用同一坐标系，这是普通逐页 PPT 最容易丢失的部分。

## 9. 是否适合继续产品化

本次结果支持继续产品化：短教材文本可以由强模型直接完成知识提炼、旁白、分镜、代码化视觉、字幕同步和 MP4 渲染，无需预定义教学模板或 MathViz capability。下一步值得产品化的是薄生产层：TTS 时长检测、字幕解析、关键帧截图审查、音视频探测、外链检查和一次 repair 管理，而不是建立海风专用 capability。

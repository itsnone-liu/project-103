# Canvas Visual Teaching Spike — 双源水波干涉 Review

## 结果概览

- 最终视频：`final.mp4`
- 代表帧：`representative.png`
- 规格：1920×1080、30 fps、60.05 秒、H.264 + AAC 48 kHz stereo
- 核心技术：Remotion + React + TypeScript + HTML Canvas + edge-tts
- repair：1 轮集中 repair

## 教学结果

视频依次建立：单源圆形传播 → 第二个同频同相源加入 → 每一点计算两列正弦和 → P 点相长 → Q 点相消 → 从瞬时场过渡到振幅包络。最终画面明确区分：瞬时位移一直变化；稳定的是由路程差决定的振幅增强区和削弱区。

P 选在两源垂直平分线上，数值上 `Δr=0=0λ`；Q 选在第一条相消线上，`Δr=0.052456`，目标 `λ/2=0.0525`，包络振幅约 `0.00263`（相对于单源振幅 1，理想零点误差约 0.13%）。

## 首版审查与唯一集中 repair

首版完整 MP4 与六张代表帧先完成，再集中处理：

1. 纠正 P 点说明：原显示“约 1λ”，但实际几何为等距，应为 `Δr=0=0λ`；旁白同步改为“到两个波源等远”。
2. 统一 S1/S2 波源标记颜色，避免视觉模型和学生把不同颜色误读为初相相反。
3. 将 Q 标签改为 `Δr≈λ/2 / 第一条相消线`，与实际数值一致。
4. 最终包络由混合瞬时正负纹理改为直接渲染 `|2cos(kΔr/2)|/2` 的稳定亮暗场，使增强/削弱双曲条纹清楚。
5. 代表帧后移到包络完全建立之后；外部视觉检查最终判定通过。

没有进行第二轮教学设计 repair；最后一次改动属于已规划集中 repair 内的包络呈现修正。

## Review Questions

### 1. Canvas 相比 SVG 是否明显更适合？

是。Canvas 每帧计算并写入完整二维采样场，天然对应“每一点都在叠加”的物理概念。若用 SVG，需要创建或更新十万级元素，或退化为少量圆环；前者不合理，后者不能展示连续场。

### 2. 每帧大约更新多少采样点？

内部缓冲为 `480×270`，即 **129,600 个采样点/帧**。60 秒、1800 帧共约 **233,280,000 次采样点更新**。Canvas 结果再由浏览器缩放到 1772×736 的显示区域。

### 3. 是否保持流畅？

是。成片稳定输出 30 fps；Remotion 完整渲染成功。采用较低内部场分辨率后再放大，在保留连续场视觉的同时避免直接逐帧计算 1920×1080 全像素。

### 4. 波场是否真的由数学函数计算，而不是预制图片？

是。每帧、每采样点实时计算 `r1`、`r2`，瞬时模式使用 `sin(kr1−ωt)+sin(kr2−ωt)`；末段包络使用 `|2cos(k(r1−r2)/2)|/2`。没有波场图片素材，也没有大量 SVG 圆。

### 5. 学生能否看懂相长与相消产生的原因？

基本能。视频不仅展示条纹，还先展示逐点求和公式，再用 P/Q 两点、路程辅助线和同相/反相条说明原因。P 强调“峰遇峰、谷遇谷”，Q 强调“一列向上，另一列向下，合振幅持续很小”。

### 6. 是否出现“漂亮但看不懂”的问题？

首版有这个风险：包络仍夹带瞬时纹理，稳定条纹不够明确；已在集中 repair 中改为直接、清楚的振幅包络，并将最终句保持在画面上。仍需注意：颜色是位移/振幅编码，不是真实水色；图例已承担这一说明。

### 7. Canvas 是否值得进入 LessonVideo 工具箱？

值得，推荐作为 `FIELD / MANY-SAMPLES / PER-FRAME` 类视觉表达器进入工具箱，特别适用于波场、热场、扩散、粒子密度、向量场、概率场和像素级状态演化。它不应替代所有 SVG；应由教学对象的数量和连续性决定。

### 8. 哪些部分仍然更适合 SVG/HTML overlay？

S1/S2/P/Q 标签、两条路程辅助线、公式、色标、进度、短解释卡、字幕和最终结论更适合 SVG/HTML。它们对象少、需要清晰排版和精确审查；放入 Canvas 会降低可读性与可维护性。

## 边界与后续

- 本实验是教学级理想标量波，不是 CFD、真实水面高度场或边界反射模拟。
- 为保持相消条件清楚，主模型采用等振幅、无阻尼；真实水波振幅衰减未加入。
- 后续若产品化，建议抽象一个纯函数 `WaveFieldCanvas`：输入源列表、波长、频率、模式（instant/envelope）、采样分辨率和颜色映射；同时保留 HTML/SVG overlay 层。

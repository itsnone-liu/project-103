# Lesson Brief — 双源水波干涉

## Core Learning Objective

学生看完后能用一句因果链解释双源干涉：两个同频同相波源各自向外传播；空间每一点同时收到两列波并线性叠加；路程差决定到达相位差；同相增强、反相削弱；长期振幅分布形成稳定干涉条纹。

## Must Teach

1. 单个点源产生向外传播的圆形波。
2. 两个波不是碰到后停止，而是共同存在并在每一点叠加。
3. 瞬时合位移使用 `sin(kr1-ωt)+sin(kr2-ωt)` 计算。
4. `Δr≈nλ` 的典型点 P 为同相到达、相长。
5. `Δr≈(n+1/2)λ` 的典型点 Q 为反相到达、相消。
6. 条纹表示振幅包络，而不是静止波纹或预制装饰。

## Secondary

- 用简洁公式显示波场来自数学计算。
- 用从瞬时波场到振幅包络的视觉过渡，建立“传播仍在继续，空间结构保持稳定”的认识。

## Can Omit / Compress

- 不推导波动方程；目标是叠加与路程差直觉。
- 不讨论相干条件的实验装置、边界反射、水深和阻尼。
- 不讲节点/腹线的严格双曲线证明。
- 不使用科研级 CFD 或三维水面网格。

## Misconception Risks

1. **把某一瞬间的暗色/零位移当成相消。** 防护：Q 点展示两分量随时间相反、合成振幅持续很小；最后单独显示时间不变的包络。
2. **认为波彼此撞散或停止。** 防护：P/Q 讲解时背景波场仍缓慢传播。
3. **认为条纹是后来叠加的一张图片。** 防护：先展示逐帧瞬时函数，再从同一 `r1,r2` 计算包络并交叉淡化。
4. **把颜色理解成水的真实颜色。** 防护：图例标注暖色=上凸、冷色=下凹、暗色=接近平衡位置。
5. **信息过密。** 防护：一次只聚焦一个问题；公式、P 点、Q 点和包络分阶段出现。

## Teaching Spine

```text
一个源如何传播
→ 第二个源加入
→ 每个像素都做一次相加
→ P：整数波长路程差，同相增强
→ Q：半整数波长路程差，反相削弱
→ 对每点观察一段时间，得到稳定振幅条纹
```

## Visual Division of Labor

- **Canvas：** 单源场、双源瞬时场、全二维连续重绘、振幅包络、两者交叉过渡。
- **HTML/SVG overlay：** S1/S2 标签、P/Q 标记、距离线、短公式、相位小表、图例、标题和字幕。
- **旁白：** 解释“为什么”；不逐像素描述颜色变化。

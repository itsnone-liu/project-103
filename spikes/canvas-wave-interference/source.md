# Canvas Visual Teaching Spike — 双源水波干涉

## 用户给定目标

验证 HTML Canvas 是否明显优于 SVG，适用于大量连续变化视觉单元、二维波场、空间干涉和高频逐帧重绘。目标受众为高中物理入门学生，成片约 45–60 秒，中文普通话旁白。

核心理解目标：

> 干涉图样不是“画出来的条纹”，而是两个不断传播的波在空间每一点进行线性叠加后的结果。

## 物理事实源

两个波源 S1、S2 固定、同频、同相。忽略真实水深、阻尼、边界反射与三维流体动力学，仅使用教学级标量波模型。

对平面采样点 `(x,y)`：

```text
r1 = distance((x,y), S1)
r2 = distance((x,y), S2)
A(x,y,t) = sin(k r1 - ωt) + sin(k r2 - ωt)
k = 2π / λ
```

由和差化积：

```text
A = 2 cos(k(r1-r2)/2) · sin(k(r1+r2)/2 - ωt)
```

所以该点随时间振动的振幅大小为：

```text
Envelope(x,y) = |2 cos(π(r1-r2)/λ)|
```

- 路程差 `Δr = |r1-r2| ≈ nλ`：两列波同相到达，振幅最大，相长干涉。
- 路程差 `Δr ≈ (n+1/2)λ`：两列波反相到达，理想模型中振幅接近零，相消干涉。
- 瞬时位移等于零不一定是相消干涉；相消必须指该位置的合振幅持续很小。
- 波仍在传播，稳定的是由几何路程差决定的振幅空间分布。

## 制作约束

- Remotion + React + TypeScript + HTML Canvas + TTS。
- Canvas 必须承担主要波场渲染；不可用大量 SVG 圆环伪装。
- SVG/HTML 只承担标签、短文字、箭头、采样点、辅助线和界面层。
- 输出 1920×1080、30 fps、约 45–60 秒。
- 最多一次集中 repair。
- 交付 `attempt-1/`、`final/`、`review.md`、`final.mp4`、`representative.png`。

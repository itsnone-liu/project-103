# Lesson Brief：扩散与渗透

## 1. 唯一核心教学目标

学生看完约 40 秒视频后，能够用一句因果话解释：

> **粒子始终做随机运动，但浓度差会造成从高浓度到低浓度的净移动；当这种“会移动的粒子”被选择性膜限制时，若溶质不能穿膜而水能穿膜，水的净移动就是渗透。**

本视频不追求学生掌握全部跨膜运输分类，而是建立“随机运动 ≠ 没有方向的宏观结果”，并把渗透理解为水通过选择性膜的特殊被动运输。

## 2. Must teach

1. 扩散的方向是**高浓度区域到低浓度区域的净移动**，不是每个粒子都单向运动。
2. 粒子的微观运动始终随机；达到动态平衡后仍在运动，只是两个方向的通量大致抵消。
3. 渗透需要**选择性/半透膜**：水能通过，溶质不能自由通过。
4. 渗透的净移动对象是**水**；在本视频采用的近似说法中，水由低溶质浓度一侧移向高溶质浓度一侧。
5. 扩散与渗透都属于不需要额外能量的被动运输；渗透是与水有关的特殊情形。

## 3. Secondary

- “细胞膜控制物质进出细胞”作为场景引入，用一句屏幕文字带过。
- 两侧初始液面相同，水移动后液面不同，作为渗透结果的视觉证据。
- 最终新的平衡状态只作简短收束，不展开压强、液柱或水势的更高阶解释。
- 选择透过性意味着不同物质通过能力不同，可在膜旁以短标签提示，但不展开通道蛋白机制。

## 4. Omit

本次明确不进入旁白主线或动画：

- 香水扩散例子：生活熟悉，但会占用时间，且不能帮助理解半透膜与渗透的区别。
- 糖入水例子：与香水功能重复，删除以避免堆例子。
- 温度升高使扩散更快：正确但会打开“速度受哪些因素影响”的新支线，不服务本次核心目标。
- 能量运输的完整分类：只保留“被动运输不额外耗能”，不讲主动运输类别。
- 通道蛋白和其他膜结构的具体机制：本视频不解释蛋白结构，避免把“不能自由穿膜”误讲成“绝对不能通过”。
- 自由水分子、溶液水势等更精确的高阶术语：用低/高溶质浓度近似表达，并明确“这里说的是水的净移动”。

删除原则不是认为这些内容不重要，而是它们不能在 40 秒内同时服务唯一主线。

## 5. Misconception risks 与防护

| 风险 | 页面/旁白防护 |
|---|---|
| 动态平衡=粒子停止 | 最终扩散面板保留两侧双向随机箭头，并显示“仍在动；净移动≈0” |
| 扩散需要外界主动推动 | 旁白说“粒子自身的随机运动造成统计上的净移动”，不画推力或发动机 |
| 渗透是溶质穿膜 | 半透膜只让水粒子通过；溶质粒子在膜前被挡住，并显示“溶质不能自由穿过” |
| 水的净移动方向说反 | 屏幕同时写“低溶质 → 高溶质（指水）”，水粒子箭头跨膜指向高溶质侧 |
| “低浓度→高浓度”对象不清 | 所有方向标签写完整的“低溶质浓度侧 → 高溶质浓度侧：水” |
| 所有物质都能穿膜 | 膜旁显示“选择透过性：不同物质通过能力不同”，且示意只允许水穿膜 |

## 6. 内容重组决定

采用“先微观机制，再选择性膜，再渗透，再比较”的顺序，而不是按教材先总述跨膜运输再列例子：

1. 先把随机运动与净移动拆开；
2. 再用动态平衡纠正“平衡=停止”；
3. 引入选择性膜作为限制条件；
4. 将同一净移动逻辑专门应用到水，得到渗透；
5. 最后用一张静态比较卡收束共同点与区别。

这个顺序让“渗透是特殊被动运输”成为前面机制的自然结果，而不是孤立定义。

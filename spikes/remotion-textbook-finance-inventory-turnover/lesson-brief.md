# Lesson Brief：存货周转率

## 1. Core Learning Objective

学生看完约 3 分钟视频后，能够完成一条完整的分析链：

> **会用同一组数据算出周转次数、周转天数和存货与收入比；能根据分析目的选择收入或成本口径；更重要的是，能用经营事件解释指标变化，而不是把“快”机械判为好、把“慢”机械判为坏。**

“会算”是入口，“看口径、看变化、看经营背景”才是本节最终能力。

## 2. Must Teach

1. **指标在问什么：** 存货占用的资金，以多快的速度进入销售并被释放。
2. **三个指标及意义：**
   - 周转次数：一年大约完成多少轮；
   - 周转天数：平均一轮占用多少天；
   - 存货与收入比：每实现一单位收入，需要占用多少存货。
3. **ABC 完整计算链：** 3000÷119≈25.2 次；365÷25.2≈14.5 天；119÷3000≈4%。
4. **口径选择：** 收入口径适合观察变现能力或与其他收入型周转率比较；成本口径在评价存货管理时更匹配，因为分子和存货都按成本口径。
5. **成本口径结果：** 2644÷119≈22.2 次，并以屏幕公式说明 25.2×成本率≈22.2。
6. **反机械评价：** 周转天数不是越少越好；指标变化必须回到经营活动解释。
7. **两个反直觉情境：**
   - 大订单先推高库存，周转天数暂升，但可能是在备货；
   - 预计销售萎缩后主动去库存，周转天数下降，但可能是经营收缩。
8. **结构视角：** 总存货不变时，内部从原材料转向大量产成品，也可能提示积压。

## 3. Secondary Information

- 现金→存货→销售→应收/现金的资金循环，仅作为指标直觉的 10 秒引入，不展开供应链。
- 收入周转次数与成本率的转换关系放在口径对比尾部，旁白只解释一次，不做长推导。
- 大订单情境保留“应付账款先增加、销售收入与应收账款随后出现”的时序，但不讲会计分录。
- 存货结构只展示原材料、在产品和产成品三个主要层次；“半成品、低值易耗品”等在屏幕角注中压缩呈现，不逐项讲解。

## 4. Can Omit / Compress

- 不平均讲教材中的每条注意事项；行业基准、季节性、历史趋势等仅在总结页用“还要比较行业与趋势”短句提示，不展开。
- 不讲平均存货与期末存货的技术差异，避免打开新的测量口径支线；可作为 5 分钟扩展版内容。
- 不展开经济订货量、安全库存、缺货成本、跌价准备等存货管理专题。
- 不讲完整现金周转周期，也不计算应收和应付周转天数。
- 不使用 Manim；本节公式不需要复杂数学对象变换，Remotion DOM/SVG 足以清楚表达。

## 5. Misconception Risks 与防护

| 风险 | 视频防护 |
|---|---|
| 周转率越高一定越好 | 两个经营案例放在全片最长段落，并用“指标方向 ≠ 经营结论”同屏对照 |
| 周转天数越低一定代表改善 | 销售萎缩案例明确显示“天数下降、需求也下降” |
| 收入法或成本法绝对正确 | 对比页标题写“不是谁更正确，而是你在回答什么问题” |
| 25.2 次等于每 25.2 天一次 | 计算链明确用 365÷25.2 得到 14.5 天 |
| 4% 是利润率 | 标签完整写“存货与收入比”，解释为收入对应的存货占用 |
| 大订单导致周转变慢就是坏事 | 时间线展示收入确认滞后于备货，强调阶段性变化 |
| 总存货不变就没有问题 | 等高堆叠柱在内部重新分配，突出产成品积压风险 |
| OCR 加号进入公式 | 所有公式由人工规范；review 对“÷、×、分式关系”逐项核验 |

## 6. 内容重组决定

原材料按“定义—计算—口径—注意事项”组织。视频改为：

1. 先用资金循环回答“为什么看周转”；
2. 把三个指标合并成一条计算链，减少公式孤岛；
3. 立即翻译 25.2、14.5、4% 的经营含义；
4. 再提出“收入还是成本”的分析目的选择；
5. 将最长时间留给两个方向相反、结论反直觉的经营情境；
6. 最后用内部结构补充“总量之外还要看组成”；
7. 以分析框架而非公式复读收束。

这样做让学生先获得计算抓手，再经历一次“数字不能自动给出结论”的认知转折。

## 7. 视觉分工原则

- **公式与结果：** 高级 PPT 式公式卡，逐步建立，留足读取时间。
- **指标直觉：** 简洁 SVG 资金循环，运动只表达资金经过存货并释放。
- **口径选择：** 静态左右对比卡 + 一次公式变换，不做无意义动画。
- **经营案例：** 真正过程动画；时间顺序本身就是因果解释。
- **内部结构：** SVG 堆叠柱重构；总高不变、组成改变必须通过运动才直观。
- **总结：** 静态卡片，让学生整理“会算—看口径—看经营”的方法。

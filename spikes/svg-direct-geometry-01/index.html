先找到“刚刚出现两个交点”的位置，再观察其中一个交点是什么时候越过 C 的。
探索结论
6(√2 − 1) < x ≤ 3

左边界来自相切：在 x = 6(√2−1) 时，两个交点合并为一个切点，所以左端点不能取。

右边界来自端点 C：x = 3 时仍有两个不同公共点，其中一个恰好是 C，所以 3 可以取；再增大 x，它便进入 C 外侧的延长线。

查看简短数学推导
取 A=(0,0)，B=(6,0)，C=(6,6)，P=(6,x)。令 AC 上一点 Q=(t,t)。
由 PQ=x，得 (t−6)²+(t−x)²=x²，即
t²−(6+x)t+18=0。
要有两个不同实根，判别式须大于 0，得到 x>6(√2−1)；再要求两个根都落在 [0,6]，得到 x≤3。

# 资金周转率 · L3 线稿动画重制方案（用户审查稿）

## 0. 内容合同

- **旁白不重写**：复用已验收 `narration.txt` 与 `final/public/audio/narration.mp3`。
- **时间轴不重做**：复用 Edge TTS `narration.vtt`，总时长约 280 秒。
- **知识口径不动**：4000÷2000=2次；360÷2=180天；提示365天口径差异；区分全部资金、固定/流动资金和营运资金；不把“越高越好”绝对化。
- 本轮只解决一个问题：把原“财务工作台/信息卡”视觉改成**跟着旁白演示概念的轻松线稿动画**。

## 1. 视觉圣经

### 画面语言

- 1920×1080、30fps、16:9。
- 暖米白纸张底色；深墨灰手绘线；主强调色用金黄（资金）；风险用砖红；效率改善用青绿。
- 4–7px不完全规整线宽，少量水墨晕染只作场景过渡，不遮文字。
- 资金由一枚有简单表情的“小钱币”角色贯穿全片，但不拟人过度、不抢教学信息。
- 主要对象都由线条“现场画出来”：使用 SVG `pathLength/strokeDashoffset` 或确定性 Canvas 路径。
- 每 2–4 秒必须发生一次**有教学语义的动作**：箭头推进、形态变化、公式部件合并、状态切换、因果结果出现。

### 生动但不花哨

- 允许：描线出现、对象沿路径运动、match cut、墨迹擦拭、纸张翻页、手写圈注、轻微手绘抖动、情境小彩蛋。
- 禁止：随机方块、通用信息卡墙、玻璃拟态、霓虹、粒子爆炸、RGB分离、无意义光晕、弹跳UI、只做缩放平移的静态页、与旁白无关的装饰运动。
- 不做写实人物；人物和企业场景用简洁白描，不出现AI生成的人脸。

### 文字与声音

- 默认只保留中文字幕，避免中英双语挤压财务公式阅读区；如需双语可后加版本。
- 所有公式、数字、指标名使用真实 DOM 文本，不把文字画进图像。
- 底部字幕安全区不被主体、箭头、图例占用。
- 音乐：轻松、克制、木琴/拨弦/轻打击风格；旁白出现时自动压低，不用“企业宣传片史诗鼓点”。
- 小音效只服务语义：金币滑动、印章、机器停转、回款“叮”、笔划完成。

## 2. 九场新分镜

### S1 一笔资金，反复工作（0–28s）

**核心画面**：一枚“小钱币”从现金池跳上手绘轨道，依次经过设备、材料、生产线、货架、发票/应收、回款，再回到现金池。

**动作节拍**：
1. 墨线从左向右画出经营环路；
2. 小钱币沿线行走，每到一站变成对应形态的局部图标；
3. 第一次回到现金池时盖下“一轮”；第二圈只快速跑半圈，建立“同一笔钱反复工作”；
4. 结尾环路缩成一个持续转动的小速度表，match cut进入公式。

**彩蛋**：生产线上一只螺丝帽追着小钱币跑两步，增强轻松感，不影响信息。

### S2 公式先看分母（28–58s）

**核心画面**：不是信息卡，而是一张手绘账本。收入从上方流入，期初与期末资金两个砝码放上天平，天平中间合并成“平均占用”。

**动作节拍**：
1. 写出“周转次数＝主营业务收入÷资金平均占用额”；
2. 放大分母，期初、期末两个墨点沿括号滑到一起，出现“÷2”；
3. 一个小手把“只看期末”的纸条划掉；
4. 小钱币举牌：“平均值更像整段时间”。

### S3 百科例题：2次/年 ↔ 180天/次（58–92s）

**核心画面**：4000万元收入画成一条金色收入河，2000万元平均占用画成一个可循环使用的蓄水池。

**动作节拍**：
1. 金色河水两次流经同一座2000万资金池，计数器从0→1→2；
2. 公式手写完成：4000万÷2000万＝2次/年，并停留至少4秒；
3. “2次”翻转成一只360天圆盘，被一条直径切成两半，每半标180天；
4. 角落手写备注：“有些资料用365天，比较前先统一口径”。

### S4 速度翻倍，占用减半（92–117s）

**核心画面**：同样4000万元收入目标，两条并排线稿轨道：慢轨2圈/大资金池2000万；快轨4圈/小资金池1000万。

**动作节拍**：
1. 两条轨道同时起跑；
2. 快轨的小钱币跑四圈，慢轨跑两圈；
3. 大资金池像气球一样收缩到一半；
4. 最终公式关系停稳，不做“速度越快绝对越好”的价值判断。

### S5 总资金里有两种节奏（117–162s）

**核心画面**：一座企业剖面图。左侧固定资金是厂房/设备，像缓慢转动的大齿轮，价值通过“折旧刻度”一点点回收；右侧流动资金是一条快速水道，在材料→在产品→产成品→应收款→现金间变形。

**动作节拍**：
1. 大齿轮每转一小格，折旧刻度回收一点；
2. 水道中的金线连续变成五种形态；
3. 两条节奏汇入同一个“总资金”表盘；
4. 重资产与轻资产两家小工厂从同一收入牌后出现，速度表自然不同。

### S6 名字接近，口径不同（162–195s）

**核心画面**：三把不同的“测量尺/放大镜”，而不是三张卡。每把尺子对准不同资金范围。

1. 全部资金周转率：放大镜框住整座企业；
2. 固定/流动资金周转率：分色镜片分别框住设备或流动链；
3. 营运资金周转率：尺子先画“流动资产－流动负债”，再放到分母位置；
4. 三把尺子想互换位置时，小钱币吹哨制止，出现“分母不同，不可混用”。

公式停留时间不少于20秒，所有文字用DOM渲染，优先正确和可读。

### S7 “越高越好？”认知转折（195–216s）

**核心画面**：一枚夸张的“越高越好”印章落下，随后一支墨笔画问号并划掉“绝对”。速度表指针继续冲高，进入砖红风险区。

**动作节拍**：
1. 信息框结论盖章；
2. 正文像旁注一样从书页边缘展开：“没有通用标准”；
3. 速度表旁出现历史、同行、行业三面小镜子；
4. 指针停在红区前，承接下一场风险情境。

### S8 快与慢，都要追问原因（216–262s）

**核心画面**：一条线稿河流分成三支，不使用抽象卡片。

- 健康加速：流程障碍被清走、应收账期缩短、闲置箱子减少，水流顺畅；
- 过度压缩：水库过浅，货架突然空了、机器停转、付款日历变红；
- 结构性慢：水电站/高速公路/大型设备像大象一样慢，但稳定运转。

三支水流最后汇回“原因”二字：快慢都不是结论，原因才是。

### S9 四步读懂资金周转率（262–280s）

**核心画面**：小钱币沿一张手绘地图经过四个检查站：会算→看口径→看结构→比历史与同行。

每过一站盖一个小印章，最后四站连成速度表外圈；镜头拉远，形成终句：

> 资金周转率是经营循环的速度表，\n> 不是脱离结构与风险的分数。

尾部停留约2.5秒，音乐收束，不加Logo和平台UI。

## 3. 工程合同

- 使用 Remotion + React/TypeScript + inline SVG/Canvas；复用当前工程依赖。
- 所有动画由 `frame/FPS` 决定；禁止依赖实时计时器和CSS transition，保证逐帧渲染确定性。
- 先实现 `attempt-1-lineart`，渲染每场中点和关键转折帧组成 contact sheet；只允许一次集中 repair。
- 音频、VTT、公式数据从单一来源读取，避免在多个组件重复手写。
- 输出：H.264 + AAC，1920×1080，30fps，约280秒。

## 4. 验收闸门

1. 每2–4秒有一次与旁白对应的语义动作，且没有纯装饰型乱动。
2. 不出现随机方块/卡片墙/通用仪表盘模板感。
3. 公式、4000/2000/2次/180天、360/365口径全部正确。
4. 固定/流动资金与营运资金口径不混用。
5. 字幕无遮挡、不溢出；关键公式停留足够。
6. 不出现品牌、水印、浏览器、MiniMax或其他UI污染。
7. 音乐不压旁白，音效只在教学动作上出现。
8. 成片时长、帧率、编码、音轨经媒体探测验证；关键帧和contact sheet人工复核。
